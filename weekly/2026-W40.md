# CLAUDE NEWS 週報 · 2026-W40

## 一、頭條敘事：API 的 sonnet 別名這週悄悄換成 Sonnet 5.5，靠別名跑自動化的人先跑回歸測試

Claude Code v2.1.284 起，API 端的 sonnet 別名指向 Sonnet 5.5，沒改設定的自動化流程已經在跑新模型。MIXED Reality News 稱 Sonnet 5 的程式碼換到 5.5 有五種行為差異，其中一種沒有錯誤訊息，細節見討論綜述。你該做的事：靠別名跑自動化的人先跑一輪回歸測試，其他人不必動。

本期兩篇專文：第一篇給在同一個長對話裡反覆引用早先結果的人，尤其用 1M 視窗的；第二篇給正在考慮因「降智」貼文換模型或停訂閱的人。各約兩分鐘。

## 二、技術討論與深挖

### 本週版本

五個版本（v2.1.284–288），建議直接升到 288：它修掉 `bash -c` 裡的危險 `rm` 在 bypassPermissions 或 shell 允許規則下不問就跑的問題（[官方 CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)，10-03 取得）。要留意的預設值變動有兩個：**v2.1.284** 把 API 端的預設 Sonnet 換成 Sonnet 5.5（1M context，每百萬 token 輸入 $2、輸出 $10）；**v2.1.287** 讓 Opus 4.7 以上與 Fable 在 Bedrock、Vertex、Foundry 與閘道上預設用 1M context，不想要就設 `CLAUDE_CODE_DISABLE_1M_CONTEXT=1`，同版起自動換模型時會保留你目前的 effort，不再套新模型的預設。其餘：285 新增 `CLAUDE_CODE_DISABLE_WEB_FETCH` 關掉網頁抓取、`claude --desktop` 開桌面版、企業管理者可用 `allowedProviders` 限制 API 供應商；287 推出 Mods（見討論綜述）。

### 討論綜述

- **外掛現在可以改 Claude Code 的深層行為**：v2.1.287 推出 Mods，並內建一個會提醒你漏掉什麼的 mod「You should know」，要自己開（`/plugin enable cc-plugin-you-should-know@builtin`）。單一媒體稱外掛可讀到你的 API Key，官方文件剛上線，本刊未核。**該不該擋**：第三方 mod 先別裝，想試就開內建那個。
- **訂閱用戶被 API Key 蓋掉**：shell 裡還留著 `ANTHROPIC_API_KEY`，Claude Code 就改走 API 計費並報「Organization has been disabled」（[#8327](https://github.com/anthropics/claude-code/issues/8327)，121 則留言，10-02 快照）。**直接做**：`echo $ANTHROPIC_API_KEY`，有值就拿掉。
- **MCP Python SDK 有帳號劫持漏洞**：資安公司 Cycode 09-28 揭露，受影響與修補版本都未公開。**直接做**：自己寫 MCP server 的人把 SDK 升到最新版，其餘等細節。
- **Sonnet 5.5 不是無痛替換**：MIXED Reality News 09-30 稱 Sonnet 5 的程式碼換到 5.5 有五種行為差異，其中一種靜默失敗，細節只有標題。API 的 `sonnet` 別名 09-28 起已指向 5.5。**直接做**：靠別名跑自動化的人先跑一輪回歸測試。
- **官方出了 Opus 5.5 專屬提示指南**（[文件](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5-5)，HN 187 分，09-28）：講 effort 校準、無人值守與多 agent 任務的寫法。**直接做**：覺得 5.5 變淺的人先讀 effort 那一節，再看第二篇專文。
- **政策與資本面，暫無動作**：Reuters 09-29 獨家取得 Anthropic 的 IPO 招股書，虧損大、成長快、首度書面警示存在性風險；FTC 09-30 對 Anthropic、OpenAI 開啟產品風險調查；Broadcom 給 Anthropic 晶片租賃的融資兩天內從考慮中的 420 億美元（Reuters）升到啟動 600 億美元（Yahoo Finance），條款未見報導；Claude for Government 10-02 對聯邦機構全面開放。

### 深挖：本期兩篇記者專文

第一篇講一個官方文件沒寫的機制，第二篇講一個沒有人拿出證據的爭議。兩篇各約兩分鐘。

#### 功能｜Claude Code 長對話會悄悄清掉舊的工具輸出，先把關鍵結果存成檔案

**發生什麼事**　工具輸出是指 Bash 結果、讀到的檔案內容、grep 清單這些塞進對話裡的東西。你知道的 `/compact` 會把整段對話壓成摘要，螢幕上看得到。另外還有一條你看不到的路：Claude Code 會把很早之前的工具輸出換成一行「已清除」，其餘對話不動，也不通知。這件事只有一個回報在講，[issue #42542](https://github.com/anthropics/claude-code/issues/42542)，04-02 開到現在沒有官方回覆（29 則留言，10-03 快照）。官方的 [context window 文件](https://code.claude.com/docs/en/context-window)沒有寫這個機制。

**為什麼 1M 的人最先撞到**　回報者說有三個機制會做這件事，觸發門檻由遠端旗標決定，不隨你的版本走。他在 1M 視窗、計數器才顯示 8 萬 token 時，早期結果就已經不在了。同一件事在 API 端是明文功能，叫 [context editing](https://docs.claude.com/en/docs/build-with-claude/context-editing)，開發者自己開、自己設門檻；在 Claude Code 裡是替你開好的。（推論）這是設計行為不是 bug，但不通知這一點官方沒有說明。

**你以為有效、其實沒有的**　設 `DISABLE_AUTO_COMPACT=true` 擋不住它，回報者試過。hook 也接不住，[hooks 文件](https://code.claude.com/docs/en/hooks)裡 PreCompact、PostCompact 只管 compaction，沒有對應這種清除的事件。升到最新的 2.1.288 也沒修，[CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) 從頭到尾沒提過這件事。（官方文件與 CHANGELOG 皆 10-03 取得）

**怎麼辦**　會在同一個長對話裡反覆引用的結果，產出當下就寫成檔案，提示裡點名檔名要它重讀。單檔壓在 5,000 token 內，超過的檔 compaction 後只會回來路徑、不回內容。查完即用的一次性輸出不必做。

#### 社群｜Opus 5.5 被降智了？先量自己的 session log

**這週吵什麼**　r/ClaudeAI 又多兩篇說 Opus 5.5 變笨的貼文：一篇推一個叫 LiveNerf 的即時基準（09-27），一篇說上線前幾天很強、現在複雜任務會失手（10-01）。兩篇都是單篇貼文，都沒有版本前後的對照，LiveNerf 怎麼量的本刊也拿不到原文。反方向也有人：09-29 有人用同一組 skills 各跑三次，分不出 Sonnet 5.5 和 Opus 5.5。官方對「有沒有降規格」沒說過話（10-03 查）。這類主張本刊已收到六則，是已知模式，不是新事。

**官方認過的那一次**　今年四月官方承認過一次真的變差（[04-23 說明](https://www.anthropic.com/engineering/april-23-postmortem)，10-03 取得），三個原因各自獨立：預設 effort 從 high 調到 medium、清 thinking 的 bug 變成每輪都清、一句要它少說話的系統提示讓評測掉 3%。全部在 04-20 前修完。注意第一個：Opus 5.5 現在的預設 effort 本來就是 medium，上期週報寫過。覺得它變淺，先看自己的 effort 設定，再怪模型。

**怎麼自己量**　挑同一個 repo、同一類任務，拿「覺得正常那幾週」和「現在」各一段比。社群工具 [CC-Canary](https://github.com/delta-hq/cc-canary)（10-03 取得）直接讀你本機 `~/.claude/projects/` 的 session log，不上網：`npx skills add delta-hq/cc-canary`，然後在 Claude Code 裡跑 `/cc-canary 30`。它會給 HOLDING 到 CONFIRMED REGRESSION 四級判定，門檻沒公布，只能當自己跟自己比。模型本身釘不住：`--model` 只吃 family 名，鎖版的要求 [#27892](https://github.com/anthropics/claude-code/issues/27892) 已被官方關掉。

**怎麼辦**　沒有自己的兩段對照，就不因貼文改設定、換模型或停訂閱。有了對照，再用 effort 設定和 CC-Canary 的判定決定下一步。

### 本週要動的事

- **在 bypassPermissions 或 shell 允許規則下跑 Claude Code 的人**：升到 v2.1.288，修掉 `bash -c` 裡的危險 `rm` 不問就跑（見本週版本）
- **跑長 session 並反覆引用早先工具輸出的人（尤其 1M）**：關鍵結果在產出當下寫成小於 5,000 token 的檔案，並在提示裡點名檔名要求重讀（見功能專文「怎麼辦」）
- **用 Pro／Max 訂閱的人**：打一次 `echo $ANTHROPIC_API_KEY`，有值就從 shell 設定檔拿掉（見討論綜述）
- **自己寫 MCP server 的人**：把 MCP Python SDK 升到最新版（見討論綜述）
- **靠 `sonnet` 別名跑自動化的人**：先跑一輪回歸測試再信任 Sonnet 5.5（見討論綜述）
- **打算因降智貼文換模型或停訂閱的人**：先挑同一 repo、同類任務的兩段 session 比較，再決定（見社群專文「怎麼自己量」）
- **想試 Mods 的人**：第三方 mod 先別裝，只開內建的 You should know（見討論綜述）
