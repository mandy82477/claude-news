### Claude Code regularly sends each background agent’s transcript to its model
- **來源：** Hacker News（slug：hacker-news）
- **URL：** https://gist.github.com/flamerix-ai/c3905705cc4205e5de3011fa2e74efce
- **日期：** 10/29 03:33 UTC
- **互動：** 527 分
- **摘要：** by Flamerix AI · MIT License Tested on Linux, Claude Code 2.1.257–2.1.312; macOS reported working by others (see Tested versions). The binary is not modified (BUN_OPTIONS=--preload). An update can silently undo it, so see Verify. Every ~30 seconds, Claude Code re-sends each background agent's full transcript to the model just to fill that agent's status line in the agents panel. no-agent-summary.j
- **日報段落：**
  > **[Claude Code regularly sends each background agent’s transcript to its model](https://gist.github.com/flamerix-ai/c3905705cc4205e5de3011fa2e74efce)**
  > 社群成員發布分析與繞過腳本：Claude Code 每隔約 30 秒就會把每個背景 agent 的完整對話記錄重新送給模型，只是為了更新 agents 面板的狀態列；作者寫的 `no-agent-summary.js`（Bun --preload）可停掉這個計時器而不修改 Claude Code 本體，在 2.1.257–2.1.312 版本測試過。今日在 Hacker News 累積 527 分，是本日討論度最高的條目。同時跑多個背景 agent 的使用者，可留意這個行為對自己 token 用量的影響。
