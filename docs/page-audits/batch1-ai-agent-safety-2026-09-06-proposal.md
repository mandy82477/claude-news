## 14. 我最沒把握的一處

**第 1 列把 Auto 模式的狀態定成 ⛔，是我對「官方認定不修」的一次擴張解釋。** 頁面既有的 ⛔ 只有兩筆，兩筆都是官方對**某個具體漏洞**的處置（symlink 結案 Informative、Session 保留期 GitHub #62476 明確拒修）。Auto 模式這筆不同：官方沒說「這個注入我不修」，官方說的是「Auto 模式這個東西本來就不是安全邊界」——那是重新定義承諾，比拒修更廣也更根本。我判它 ⛔ 的理由是**對讀者的後果完全相同**（別等修補，去隔離），而且證據等級與 symlink 那筆同級（皆為 HackerOne informative 結案）。但如果你認為 ⛔ 應該嚴格保留給「官方對具體缺陷說不修」，那第 1 列就該是 🔴＋在「官方擋到哪」格寫那句立場——**表上少一個強訊號，但符號定義不會被撐開**。這是我唯一沒有辦法用機械證據結掉的判斷。
