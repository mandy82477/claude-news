## 3. `## 現在會打到你的`（Q1／Q3 的核心交付）

**判準句（三條全過才入表）：① 是現在還打得到讀者的攻擊面——論述文章、教學、產業對照、第三方廠商動態、以及「別人拿 Claude 打別人」的濫用態勢都不入表；② 「誰會遇到」欄寫得出使用條件（開 Auto 模式／接第三方 MCP／clone 他人 repo／讓 agent 裝套件），寫不出條件就寫「所有人」；③ 「你能先做什麼」寫得出一個今天做得到的動作，或明寫「無繞法」，兩者皆答不出的留在證據層。同一個讀者動作觸發的多起事件合為一列。上限 11 列。排序：依「誰會遇到」的範圍由寬到窄，**寫「所有人」的一律在最上**，同寬依最後動態新者在上。退場（依序問，第一個成立即定案）：(1) 狀態翻 ✅、或轉 ⛔ 且官方給出替代做法 → 移除該列，條目留在事件記錄；(2) 距最後動態逾 90 天且本輪無新回報 → 移除該列；(3) 其餘留表。表滿載時，讓位者是依本排序落在上限之後的那些列，在其事件記錄條目末加「（未列入現況表：表滿載，YYYY-MM-DD）」並在表下一句點名。移除後表未滿載時，從事件記錄挑仍符合三條判準、最後動態最新者補位，並移除其條目末的註記。**新列進表的入口只有兩種訊號：官方或研究者公開一個新的攻擊面，或既有事件首次出現「讀者能自己做的一件事」；單純的媒體轉述、論述文章與熱度回升不構成入口。**

狀態沿用 [[entities/claude-code]] 的五值 🔴／✅／⛔／❓／🔎，**但語意在本頁是「現在仍會發生」而不是「未修復」**——本頁半數條目是第三方濫用而非產品缺陷，「未修復」對它們不成立。表上一句已寫明這件事（draft §D）。
