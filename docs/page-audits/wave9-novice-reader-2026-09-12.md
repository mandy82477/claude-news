# 市場小白讀 market-signals 的實測心得（2026-09-12）

我是一個寫程式的，每天用 Claude Code，股票只買過 ETF，沒買過個股。以下是我從頭到尾讀完這頁的真實反應。

## 1. 總評

**3.5 / 5。** 它比我預期好讀——每則都有「一課」，我真的學到兩三個可以拿去套的判斷方式（例如「公告是敘事，財測是數字」）。但扣分在兩件事：**這頁有八成內容在講一家我根本買不到的公司**（Anthropic 未上市），讀完最實際的結論是「什麼都不做」；以及**術語沒人幫我解釋**，S-1、信評、投資級、承銷、Series H 全都是直接用，我只能猜。

## 2. 我實際怎麼讀，哪裡卡住

**我的讀法**：先看第 37–38 行那個「最新判讀」方框 → 跳過摘要（第 42–46 行，看起來像使用說明）→ 直接滑到「近期判讀」看標題 → 挑了最上面那則看完 → 往回翻兩張表 → 最後「追蹤中的里程碑」我只掃了一眼就關掉。**回顧結算表和里程碑那兩節我基本沒讀。**

卡住的地方：

- **L44**「每則判讀照分析師看消息的六個問題寫：**這是新資訊嗎、動到哪個數字…**」——我看到「六個問題」就開始數，數到第五個「下一個會讓答案變清楚的事件」的時候已經不知道自己在幹嘛了。第一次讀這頁的人不需要知道你的六個問題，我需要的是先看到一則例子。
- **L46**「只有會進 S-1、或會改變 S-1 數字的六類消息才寫上來」——**S-1 是什麼？** 這頁從頭到尾出現 S-1 大概十次以上，沒有任何一處解釋它是什麼。我最後是從 L193「公開版 S-1（唯一會揭露真實財務的文件）」這個括號才猜出來，但那已經是第 193 行了。
- **L46** 同一句「（一手財務揭露、上市流程硬事件、實際成交的資本事件、帶金額的營收訊號、機關出手的監管事件、帶數字的競爭變化）」——六個名詞連著讀，我一個都沒記住，而且我不覺得我需要記。
- **L58**「IPO 決定股票怎麼賣，信評決定日後怎麼借錢、利率多少」——這句我讀了三次。**信評是誰在評？評什麼？** 後面 L117、L125 有提到「標普、穆迪」和「債權由信評機構評等」，但我還是不知道「投資級」是什麼等級、為什麼拿到就能借得便宜。這一課我看完還是半懂。
- **L72**「Alphabet、Amazon 為既有投資人，間接曝險佔各自市值極小」——「**間接曝險**」這個詞我卡住了。我猜意思是「我買 Google 股票等於間接買到一點點 Anthropic」，但「佔市值極小」到底是多小？0.1%？5%？整頁重複講「間接曝險」至少六次，卻一次都沒給數字。
- **L100**「硬度：單一標題」——「單一標題」我第一次看以為是「只有一個標題黨」的意思，後來才懂是「只有一家媒體寫了一個標題、沒內文」。
- **L102**「Anthropic 官方確認的 $9,650 億（Series H）或傳聞的 $2 兆」——**Series H 沒解釋**；另外 9,650 億跟 2 兆放在一起，我一開始以為單位不同（一個億一個兆），要停下來算才知道差一倍多。
- **L161**「同日 Anthropic、OpenAI、xAI 三方模型服務同步中斷且皆未說明原因…但三方均未上市，不另立判讀」——這句在講「我為什麼不寫這件事」。**我不需要知道你沒寫什麼**，這對我是雜訊。
- **L211–212** 回顧結算表裡的「撤回（2026-09-12 改版：關注度訊號不寫判讀）」——**完全看不懂**。「改版」「關注度訊號」是什麼？這兩行像是給別人看的內部備註，我讀到會愣一下。
- **L227–235** 整個「追蹤中的里程碑」——`❓ **待查證**（標 2026-09-11｜查 出口管制、國防部｜複 2026-09-25）` 這種寫法我看不懂。「標」「查」「複」三個字各自後面接日期或詞，像某種表單代碼。我直接跳過整節。

## 3. 我學到什麼（老實版）

能用自己的話講出來的：

1. **「宣布合作」跟「上修財測」是兩回事，只有後者會影響分析師算出來的數字。** 來自 08-26 Salesforce 那則（L182–185）。這條最有用，因為我以後看到科技新聞說「某某大廠宣布跟誰合作」就知道那可能只是故事。
2. **兩家媒體都在抄同一個消息，跟兩家各自問到公司，是不同等級的可信度。** 來自 09-06 那則的一課（L152–155）「分兩堆——引述公司公告的、轉述的」。這個我覺得很實用，可以直接拿去讀任何新聞。
3. **「傳某某銀行負責辦 IPO」不等於估值被證實。** 來自 09-04（L167–170）。半懂——我懂「流程 ≠ 數字」這個邏輯，但我還是不知道「主辦銀行」在 IPO 裡到底做什麼。
4. **比兩家公司的估值之前，先看它們是不是賣同一種東西。** 來自 09-09 Cognition 那則（L108–111）。這條我懂而且覺得有道理。

講不出來的：

- **「股權與債權是兩條進度」這課我看完還是不懂**（L123–126）。我知道「股票」跟「借錢」不一樣，但我不知道信評機構是誰、為什麼一家還沒上市的公司要先去弄信評、「投資級」是好是壞。
- **「祕密遞件不等於時間表」這課我只懂一半**（L197–200）。我不知道什麼叫「機密遞件」、遞給誰、為什麼可以不公開。
- **「自揭濫用是雙面刃」這課我懂道理但覺得跟我沒關係**（L93–96）。它講的是「公司自己爆自己的料，好壞都有」——這我懂，但後面那句「替監管收緊供彈藥」我要想一下才知道是「政府可能因此加強管制」。

## 4. 重複感（有，而且蠻明顯）

- **每一課都寫了兩次。** 表格（L54–62）每列的「一句話」和「下次怎麼認」，跟下面判讀裡那一課的文字**幾乎一字不差**。例如 L57「私募估值互比之前，先確認兩家賣的是不是同一種東西」對照 L109「私募估值互比之前，先確認兩家公司賣的是不是同一種東西」。我讀到第三則就發現「這我剛剛在表裡看過了」。
- **「你的選項」的 (a) 幾乎每則都一樣。** L91「(a) 什麼都不做」、L106「(a) 什麼都不做，兩者皆未上市」、L121「(a) 什麼都不做」、L136「(a) 什麼都不做」、L150「(a) 什麼都不做」、L165「(a) 什麼都不做」、L180「(a) 什麼都不做」、L195「(a) 什麼都不做」——**八則有八則**。看到第四則我就不看 (a) 了。
- **「Alphabet、Amazon 間接」出現在 L85、L115、L130、L144、L159、L189**，六則一模一樣。
- **「未動任何數字／未動任何財務數字」** L38、L72、L73、L85、L115、L159 反覆出現。
- **「把 X 設為複查點」** 每則的 (c) 都是這句型，L91、L106、L121、L136、L150、L165、L180、L195。

## 5. 第一行的符號和欄位，我一秒懂嗎

- **📈📉⚖️〰：懂一半。** 📈 我一秒懂（好消息），⚖️ 看到「兩面」兩個字才懂，**〰 我完全猜不到**——我以為是「持平」，讀到「未定」才知道是「還不知道」。整頁沒有圖例。而且我從頭到尾**沒看到任何一個 📉**，所以我不確定是不是真的有壞消息會被寫進來（雖然 L29 有一句說利空覆蓋比較弱，但那句藏在最上面的長段落裡）。
- **「誰有感」：這欄最有用，我一看就懂。** 尤其 L174「Salesforce（NYSE: CRM）」——終於有一個我買得到的東西。其他則寫「Alphabet、Amazon 間接，幾乎無感」其實等於在說「跟你無關」，那我就跳過了。
- **「硬度」：懂，但值域我不知道。** 「官方一手」「跨媒體與社群多來源」「單一標題」——我大概排得出順序，但不確定還有沒有別的等級、哪個算及格。
- **「線：IPO 進程 ▸ 第 5 則」：懂。** `▸ 開線` 我第一次看不懂，但看到「第 2 則、第 3 則」之後回推就懂了。
- **標題前的 💰 我不知道幹嘛用的**，每則都有，等於沒區別。

## 6. 兩張表有用嗎

- **「一課一課學」（L50–62）**：我是**先看判讀才回頭看表**的。當索引用不錯，但因為跟下面完全重複，我不會兩邊都讀。「押對了嗎」整欄全是 ⏳，**這欄現在等於空的**，我看不出它想告訴我什麼——如果一個月後還是全 ⏳，我會覺得這欄是裝飾。「例題」欄寫「09-11」「09-06、09-07」，我要自己滑下去找對應那則，**很麻煩**。
- **「現在在動的敘事線」（L66–75）**：這張**比較有用**，因為「標的與可交易性」那欄直接告訴我「這個你買不到」「這個 NYSE: CRM 可以」。我覺得這欄應該放到全頁最上面。但「則數 · 最後一則」那欄對我沒意義（我不在乎你寫了幾則），「這條線的課」又是第三次重複同樣的課名。
- **老實說：如果只留一張表，我會留敘事線那張，砍掉課程表**（因為課的內容在下面都有）。

## 8. 最想改的三件事

1. **給我一個名詞小抄。** S-1、信評／投資級、承銷／主辦銀行、Series H、機密遞件、間接曝險——六個詞，一句話一個，放在頁面上方（摘要之前）。現在這些詞散在各則裡靠上下文猜，像 L46 第一次出現 S-1 就直接用。有了小抄，L123「股權與債權是兩條進度」那課我大概就懂了。

2. **砍掉重複，把八則的 (a)(c) 收成一句共用的話。** 具體：`你的選項` 裡的「(a) 什麼都不做」和「(c) 把 X 設為複查點」寫死八次沒有資訊量（L91/106/121/136/150/165/180/195）；建議每則只留 (b)——真正有差異的那一項——然後在「近期判讀」節標下加一句「未上市標的的預設動作一律是什麼都不做，以下只寫例外」。同理，課程表和判讀裡的一課**留一份就好**，表格那份可以只留「課名＋例題連結」。

3. **把「這跟我有沒有關係」提到最前面，順便給 📈⚖️〰 一行圖例。** 現在我要讀到 L72 的表格才知道「Anthropic 你買不到」。建議把敘事線那張表（L66–75）搬到「最新判讀」方框正下方，並在表上加一行：「📈 偏正面／📉 偏負面／⚖️ 好壞都有／〰 還看不出來」。另外 L211–212 那兩行「撤回（改版：關注度訊號不寫判讀）」和整節「追蹤中的里程碑」（L227–235）的 `標／查／複` 寫法，對我來說是看不懂的雜訊，建議收起來或換成人話（例如「等：Moonshot 官方回應，預計 9/25 前後再看一次」）。
