## 四題

### Q1 該用 Managed Agents／`/goal`／Agent SDK？ ❌ 沒拿到（4 跳仍無單一建議）
全庫沒有一處把這三個放在一起比。我拿到的是三塊互不相認的碎片：
- managed-agents **L56–57**：「最適合：長時間跨 session、需可驗證輸出的 Production Agent／不適合：快速原型、一次性任務、預算有限的個人開發者」——**唯一接近分界的一句**，但「預算有限」沒有數字，我不知道自己算不算。
- feature-radar **L224/L226**：`/goal` 🔥🔥🔥🔥 ✅推薦 vs Managed Agents（全套）🔥🔥🔥🔥🔥 ⚡有條件。兩個評級擺在一起，沒有一句話說「你這種情境選哪個」。
- coding-workflow-guide **L454/L458**：`/goal` 怎麼寫條件——但它預設我已經選好了。
- Agent SDK 在這條線上**完全不出現**；它只以「計費風波的受害者」身分出現在 pricing 頁。
卡點原句：managed-agents **L135**「**社群替代方案**：Opus 決策層 + OpenCode 執行層的自組架構仍是可行選擇」——丟出第四個選項卻不給選擇條件，我更難決定了。

### Q2 能不能用、穩不穩、有沒有人在用？ ⚠️ 半拿到（2 跳，官方說法為主）
- 官方面清楚且**這頁最好的一段**：**L46**「框架整體已正式發布（2026-05-11 起），但子功能成熟度不一」+ L142–153 逐項狀態表（僅 `/goal` 正式發布，Dreaming/Agent View 研究預覽，其餘公開測試）。
- 使用者回饋面**近乎零**。全頁唯二「有人在用」的證據：L136 Reddit 70 天開發者——但讀 L135 才發現他用的是**自組架構不是 Managed Agents**；L208 Boris Cherny 數千子代理——他是 Claude Code 創始人，這是官方自己人。
- feature-radar **L235** 對 Dreaming 直接寫「**尚無採用回報**」。
結論：我拿到的 100% 是官方說法 + SDK changelog，**沒有任何一則獨立第三方生產環境回饋**。

### Q3 怎麼計費、比自己跑貴多少？ ❌ 完全沒拿到（4 跳）
managed-agents 全頁零次出現「計費／定價／$」，也沒有 `[[entities/pricing]]` 連結——這是**整條線最大的斷點**。我自己繞回 index 開 pricing，只查到 Agent SDK／`claude -p` 的計費切割 **L114**「已於 2026-06-16 暫停…重新推行時間未定」。Managed Agents 本身怎麼算錢，全庫給不出一個字。而 L57 卻拿「預算有限的個人開發者」勸退我——**用我查不到的東西當勸退理由**。

### Q4 Dreaming 是什麼、對我有什麼用？ ⚠️ 半拿到（1 跳）
