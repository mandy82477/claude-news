### 5. 「這是在騙我／撐不起」的句子

- discussions `:65`｜「本頁先前寫的『90%』查不到出處，已依外部研究改寫」——誠實加分，但 `:659` 的 90% 標題還在，兩句放在同一頁互相拆台。
- discussions `:53`｜Skill Atrophy 證據硬度寫「官方一手研究 ＋ **多則單一貼文自述**」——「多則單一貼文」自相矛盾，讀起來像在幫弱證據撐場面；但 `:101`–`:104` 逐則標了「單一貼文、互動數據不明」，反而比表格誠實。
- discussions `:61`｜「僵住」＋硬度「單次高互動討論 ＋ 官方部落格一則」——一次討論撐一場「爭論」，門檻偏低。
- discussions `:104`｜「（HN 13 分）」——13 分被寫進一場全站級爭論的最新證據，數字自己說明它撐不起。
- discussions `:150`｜「HN Repo Bridge score 303，**惟僅擷取兩則留言**」——303 分只讀了兩則留言就下結論。
- patterns `:207`／`:216`／`:326`｜「星數（9.3 萬）規模遠超收錄門檻，**惟僅取得 GitHub Search 星數，無 forks／issues／近期 commit 佐證**」——連續多則同一句自白，讀者會開始懷疑整個「代表技巧」欄。
- **結論表能不能對號照做**：`## 現在吵到哪` 可以（每列我都答得出「這關不關我的事」）；`## 最近在討論什麼`（:148 起 46 列）不行——`:158`、`:163`、`:165`、`:168`、`:169` 連續五列都是「Simon Willison 引述某人說了一句話」，🔥 一格、☄️閃現，對我的決定零幫助，卻佔掉表格一半。
