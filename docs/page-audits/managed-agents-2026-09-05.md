2. **`signal: 健康` 判錯（🟡）**：讀 `scripts/gen_wiki_frontmatter.py` L296–302 原始碼——四象限只吃「入鏈數 × 距上次新聞天數」（`days=16` < `STALE_DAYS=21`）。**`pending_overdue` 完全不進 signal 計算**，所以「2 筆懸置皆逾複查日 12 天」的頁被標健康。這是訊號定義缺一個維度，不是本頁的錯（`check_pending_markers.py` 有抓到：`entities/managed-agents:42`、`:211` 各逾期 12 天）。
3. **觸發條件與進料錯配（🟡）**：規則檔寫「Managed Agents 框架更新」，實際只有 SDK release note 進得來，而 release note 從不說子功能成熟度 → 核心功能表狀態欄永遠不會被觸發更新。
