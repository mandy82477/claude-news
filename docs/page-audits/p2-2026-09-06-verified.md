## 四、給設計者的三句話

1. 版本這件事三處在記（radar 升版風險、radar 月節、claude-code 最新版本 121 列）——官方只有一份 changelog，本站不需要三份副本，需要的是「從你的版本到最新版之間有沒有 breaking／預設值改變」這一個答案。
2. 品質退步有官方結案版本號（v2.1.116），頁面卻還掛著「是否已恢復」的懸置 27 天——這類有一手來源可查的懸置，記者查不到是因為沒 web 工具，設計時要留「主編查證」的出口。
3. 10 筆逾期懸置 7 筆今天結案，全是「單一媒體報導 → 兩週後官方文件已有」型；懸置複查日訂兩週對這類條目太短或太長都不是問題，問題是沒人查。

## 六、版本階梯原料（`gh api` 抓完整 CHANGELOG.md 6,358 行，本機 grep；2026-09-06 UTC 22:2x）

第一節「⚠️ 未重驗」兩處已解：**v2.1.212／v2.1.215 逐字確認**（「`/fork` now copies your conversation into a new background session…the in-session subagent it used to launch is now `/subtask`」；「Claude no longer runs the `/verify` and `/code-review` skills on its own」）。2.1.205–2.1.261 全部在 changelog（2.1.213、230、242、249、250 之類跳號是官方沒發，不是本站漏報）。

**不算 breaking、但會改變 subagent／hook／MCP 使用者行為的「預設值改變」**（設計者版本階梯表的原料，逐條出自 changelog 原文）：

| 版本 | 改變（讀者語言） | 誰會碰到 |
|---|---|---|
| 2.1.207 | auto 模式不再讀 repo 內 `.claude/settings.local.json` 的 `autoMode`；plugin 設定只讀 user／managed | 靠 repo 設定開 auto 的人 |
| 2.1.212 ⚠️ | `/fork` 改成複製對話到新背景 session；同 session 子 agent 改叫 `/subtask`；Task 工具 `mode` 參數作廢 | 巨集／skill 依賴 `/fork` 舊行為 |
| 2.1.215 ⚠️ | `/verify`、`/code-review` 不再自動觸發 | 靠自動驗證當隱性保護的流程 |
| 2.1.217→219 | 巢狀 subagent 深度預設先關（217）再開到 3（219）；`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` 控制 | 多層 agent 流程 |
| 2.1.218 | `/code-review` 改背景 subagent；`context: fork` 的 skill 預設背景跑；`/deep-research` 不再自動啟動 | 用 skill／review 的人 |
