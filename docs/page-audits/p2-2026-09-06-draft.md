> 最新 v2.1.261（09-04），v2.1.238 起無 breaking change。兩個預設值換了：Fable 預設模型改 5.1（v2.1.257）、auto 成為預設權限模式（8/14 起，與版本無關）。

## ⭐ 這禮拜值得跟的三件

- **Claude Code Auto 模式已預設化**：8/14 起 auto 成為 Pro／Max／Team 預設權限模式，取代手動確認。**怎麼開始：** 打 `/permissions`，在 Auto 分頁確認要不要關掉——靠手動確認做安全把關的人尤其要看一次。
- **Claude Fable 5.1**：09-01 發布的新一代旗艦，快取讀取費率降至基礎輸入價 0.025 倍。**怎麼開始：** 升到 v2.1.257 以上，Fable 的預設就是 5.1；用 `/model` 確認現在跑的是哪一個。
- **Claude Opus 5**：07-25 發布，編碼與知識工作評測逼近 Fable 5、官方稱定價為其一半。**怎麼開始：** `/model` 切成 Opus 5。

## 品質退步當前狀態草稿

**當前狀態：** 2026 年 4 月那次退步已由官方結案。Anthropic 04-23 說明三個原因——預設 reasoning effort 由 high 調為 medium、快取問題每輪清掉 thinking、system prompt 字數限制致評測下降約 3%——並載明三者皆於 **v2.1.116（2026-04-20）** 修復，同時重置所有訂閱者用量。

此後的兩批訊號是另一件事：06 下旬起的 token 消耗異常、07-25 起的 Opus 5 品質感知，官方對這兩批都沒有對應說明。

**你的選項**：想確認自己是不是真的變慢，先用 session log 比對量一次（工具見本頁「現在就能下的解」）；想等官方對 06／07 兩批給出說明，本頁會記；現有證據不足以支持「換一個模型就好」——三批訊號沒有一批指向特定模型版本。
