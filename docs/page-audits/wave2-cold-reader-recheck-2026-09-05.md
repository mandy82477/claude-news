## 四題

### Q1 `/goal` vs subagent vs Managed Agents vs Agent SDK
**拿到。2 跳。** L68–73 的四列表直接回答我的處境：我要跑數小時、跨 session，落在 Managed Agents 那列；分界句是「單一 session 內跑得完」vs「要跑數小時以上並跨 session 保留狀態」——我對得上號，不用猜什麼叫「複雜任務」。
L92 還補一句我沒問但需要的：先用 `/goal` 把完成條件立起來，什麼都不做也是選項。這是全站最好的一段。
無卡點。唯一小疙瘩：表第五欄「現在拿得到嗎」寫「10 個零件中只有 `/goal` 正式發布」，但 `/goal` 在同一張表是**另一列**，讀起來像在說 Managed Agents 內含 `/goal`——要往下讀到 L96 的零件表才確定確實內含。

### Q2 能不能用、穩不穩、有沒有人在用
**拿到，且是我今天最滿意的答案。2 跳。**
- 官方說法：L43「beta，自 2026-05-11 起所有 API 帳號預設可用，須帶 `managed-agents-2026-04-01` beta header」，附官方文件連結。
- 使用者回饋：L45「獨立第三方生產環境回饋至今為零——本頁引用到的兩則使用案例，一則用的是自組架構、一則來自 Claude Code 創始人」。
這句是整份複驗的最高分。它沒有假裝有社群驗證，還主動說破那兩則案例為什麼不算數（其中一則是官方自己人）。L45 另註「實質新功能停在 2026-05-22；此後四筆全是 SDK 版號擴充」——這是「官方在不在推它」的答案，我沒想到會有人替我查。
唯一模糊：L45 說「零」，但我不知道這個「零」的搜尋範圍多大（是這個庫沒收到，還是世界上真的沒有）。

### Q3 計費、比自己跑貴多少
**前半拿到，後半誠實答不出。2 跳。**
- 計費：L80 token 牌價＋$0.08/session-hour（只計 running）、web search $10/1,000 次、`inference_geo:"us"` 1.1×；L81 給官方算例 Opus 5 跑 1 小時 50k in/15k out ≈ $0.705，附定價文件連結與查證日。這是我能直接拿去估預算的數字。
- 「比自己跑貴多少」：L83 明說唯一的第三方成本數字（Reddit 宣稱成本低最多 75%）**本庫未採信**，理由是未附測試方法與資料集。我接受這個答案——它告訴我「沒有可信對照」比隨便給我一個倍數好。
卡點（唯一真卡）：$0.08/session-hour 對比的基準是什麼？我自己跑 `/goal` 是「計入訂閱配額」，Managed Agents 是「token 牌價」——**訂閱配額和 token 牌價不是同一種貨幣**，我算不出換算。頁面沒說我 Max 訂閱跑 `/goal` 一小時「相當於」多少錢。

## 指定回答

**首屏（前 35 行）有沒有路走到 Managed Agents？** 有，**L31**：「我想讓 agent 自己跑幾小時／過夜，該用哪個（`/goal`、subagent、Managed Agents、Agent SDK）→ [[entities/managed-agents]]「你該用哪個」」。這一行用**我的處境**寫的、不是用產品名寫的，四個候選全列在括號裡，還直接指到頁內節名。這是我今天唯一一次沒有猶豫就知道該點哪裡。

**有沒有 SDK 程式碼？** **沒有，一行都沒有。** 頁面連 `import anthropic` 都沒出現。想照著做時它指了三個地方：L78 changelog（給 `/goal`）、L134 官方總覽文件、L73 只給版號（Python SDK v0.100.0+／TS v0.95.0+）。指路是有的，但**沒有任何一個連結被標成「這裡有可跑的範例」**——我得自己去官方站賭。對一個叫「你該用哪個」的頁來說可以接受；對一個 beta 框架的唯一入口頁來說，缺一段 10 行的最小可跑範例。

**有沒有說 beta 還是正式版？信得過嗎？** 說了，而且說了**四次**且四次一致：frontmatter status、L29 標頭、L43 現況、L72 表格第五欄。信得過——L43 附官方概覽文件連結，beta header 字串 `managed-agents-2026-04-01` 具體到可以直接貼進 code。更關鍵的是 L96–111 的零件表把「beta」拆成十格（正式發布 1／公開測試 5／研究預覽 2／公告無後續 2），**沒有拿整包 beta 蓋過個別零件的差異**。這比單寫「beta」誠實得多。

**熱的還是冷的？標示一致嗎？** 讀完的感覺是**明顯在冷卻**：新功能停在 05-22（L45）、兩項公告逾 100 天無下文（L108–109）、第三方生產回饋零、近 4 週日報只提及 2 天而且其中一次是被人拿來當對照組打（L60）。
標示：🔥🔥／⚡ 有條件推薦——**一致，而且是我看過最誠實的一次**。L60 甚至公開寫出「本次為編輯判斷而非規則計算」，還附了查證指令與命中日期。feature-radar L226 同為 🔥🔥／⚡，兩頁沒有打架（我特地去對了）。

## 三個最想改的地方

1. **「你該用哪個」表補一列「換算基準」，或在選型細節加一條「訂閱配額 vs token 牌價怎麼比」**（L68–73 / L80）。這是 Q3 唯一真卡點：表上兩種計費是兩種貨幣，讀者拿不到「貴多少」的答案，而那正是他點進來要問的第三題。
2. **加一段最小可跑範例，或把某個連結標成「範例在這」**（L73 Agent SDK 列旁、或 L134 參考來源）。整頁零程式碼，讀者決定要用之後，下一步是斷的。
3. **Dreaming 補一句「對誰有用」**（L82 或 L103）。現在只有機制＋「碰不到」，缺「等它開放了，我這種跑過夜工作流的人會差在哪」——而「尚無採用回報」這個關鍵事實躲在 feature-radar L235，本頁沒有。

## 內部用語外洩（逐句）

L60 整段是最嚴重的一處，讀起來像編輯部在對自己交代工作：
- 「**降到 🔥🔥 的一次性下修（2026-09-05 頁面健檢）**」——「頁面健檢」「一次性下修」是他們的作業名稱，不是我的語言。
- 「`python scripts/news_mentions.py --since 4w --any "Managed Agents" "受管代理"`」——**把內部腳本指令直接印在讀者面前**，我既跑不了也不需要。
- 「現行「連續 4 週零命中 −1 格」對本頁降 0 格，故本次為**編輯判斷而非規則計算**」——這是**預先辯解**：在說「我知道我的規則沒要求我降，但我還是降了，別怪我」。讀者不需要知道他們的降級規則長什麼樣。
- 「`wiki/feature-radar.md` L226 同步」——直接寫出另一個檔案的**行號**，這是維護者對維護者說話。

L66「以下分界只填本庫查得到出處的欄位，查不到的留 `—` 或標為待查證，**不以通用工程常識補**」——這句是他們的編輯守則（在對自己或對下一個寫手交代紀律），不是給我的資訊。我只要知道空格代表沒查到就夠了。

L83 小標「成本對照的唯一第三方數字，**本庫未採信**」——「本庫」是內部自稱。改成「唯一的第三方成本數字，方法未公開」對讀者一樣清楚。

L87「⟨Q-02⟩ ❓ **待查證**（標 2026-08-10｜查 anthropic-sdk-python、Managed Agents API）」——括號裡的 `標 …｜查 …` 是他們的追蹤 metadata（誰哪天標的、拿什麼關鍵字掃），對我毫無意義，卻佔了整條最顯眼的位置。

L98「資料截至 2026-09-06（**狀態每週複查**，以 [[feature-radar]] 為準）」——「每週複查」是作業節奏；勉強可接受（讓我知道新鮮度），但寫成「每週更新」就夠。
