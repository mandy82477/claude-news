## 3. 分不出差別的兩頁

**`topics/skill-interest-watch`（興趣類別 skill 總覽） vs `topics/community-tech-tools`（社群工具目錄）** —— 這兩頁我到最後都說不出「A 看這、B 看那」，而且被它們害了三次（Q1 裝錯名字、Q2 以為沒東西、Q4 拿到過期證據）。

為什麼分不出：

- 兩頁**都**有一張叫「我卡在這裡」的決策表，欄位一模一樣（症狀／先裝這個／什麼時候改裝別的／證據），前八列內容也幾乎一樣。`skill-interest-watch.md:99-101`、`:140-142`、`:156-158`、`:191-194`、`:217-219` 甚至把同幾列**在同一頁裡重印了五次**（標題叫「本庫判斷（同頁首決策表對應列）」）。我第一次以為是我捲錯位置。
- index 兩邊的鉤子都在講同一件事：`index.md:27`「我卡住了…**社群首選**是哪個 →〔skill-interest-watch〕」對上 `index.md:99`「〔community-tech-tools〕先查『我卡在這裡』症狀決策表拿首選」。**兩行都叫我去拿首選。**

我讀到哪一句才（沒）弄懂：

- 真正講清楚的是 `community-tech-tools.md:44`：「`[[topics/skill-interest-watch]]` 是這張決策表的每日副本，外加各類 GitHub 規模榜——**判斷只寫在這一頁**，想知道某一類現在誰大、本週誰在漲就去那邊。」這句一句話解決，但它在**第 3 跳那頁的第 44 行**，而我是從第 2 跳那頁過來的，早就已經被 Harness 騙過一次了。
- 第 2 跳那頁也有對應的話（`skill-interest-watch.md:40`「完整證據、推薦細節…在 community-tech-tools」），但它前面三行（`:37-39`）先跟我說「**該裝哪個**：看『我卡在這裡』決策表——有人判斷過，帶證據等級與判定日」，等於叫我就地吃這張表。我就地吃了，吃到的是舊的。
- 補一刀：`skill-interest-watch.md:46` 寫「最多落後一天」，今天落後的**不只是日期，是首選的名字**。對讀者而言「落後一天」聽起來無害，實際後果是裝錯 repo。
