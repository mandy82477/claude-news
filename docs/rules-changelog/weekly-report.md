**W36 頭條標題三次修稿（三次的病各不相同）**：

- **太抽象（看不懂）**：「Anthropic 本週把安全預算花在三個地方，沒有一個是你的 agent 讀進來的網頁。」——「安全預算」是撰稿者發明的比喻、沒有指涉物；「三個地方」要讀到第三段才知道；對比結構的兩端讀者當下都還不知道。
- **矯枉過正（太生硬）**：「請 Claude Code 摘要一個網頁，就可能被拿到機器的執行權；官方說不修——擋它的從來不是分類器，是沙箱。」使用者回「好生硬」。三個事實硬塞一句、公文腔動詞、而且「分類器／沙箱」在標題位置讀者還沒見過。
- **定稿**：「讓 Claude Code 讀一個網頁，就可能有人在你電腦上跑程式——而官方說，這不算 bug」。一個動作、一個後果、一個轉折，就停。

**頭條標題為何會靜靜死掉**（「規格沒寫下來的東西會靜靜死掉」的標本）：W30–W34 五期，頭條標題與 `> **本週一句話**：` callout 兩者都有，講的是同一件事的具體版與抽象版（W34：callout「Anthropic 對投資人報出 650 億美元年化營收的同一週，付錢的人在問…」／標題「兩份帳，同一台機器」）。W35 兩者一起消失，冷讀者實測抱怨「掃到標題行時什麼都不知道」，於是 09-04 立了 callout 那條規則——**修的是症狀**：真正沒被寫下來的是頭條標題，渲染層一直支援、五期一直在用，但規格從來沒提過它，所以沒有任何東西擋得住它消失。W36 依 09-04 的規則補回 callout，頭條標題仍是空的，直到使用者指出兩者重複，兩者才於 2026-09-06 合併成一句。
