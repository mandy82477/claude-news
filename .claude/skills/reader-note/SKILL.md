# 記一下（讀者筆記收件匣）

使用者要記的專案內容，一律進 `wiki/reader-notes.md`。週報（`/weekly-report`）與每週回顧（`/wiki-weekly-review`）會讀它；auto-memory 記憶檔讀不到，只放協作偏好。

**使用者怎麼用：** 說「記一下：…」即可，不需準備；我會回報寫進哪個檔、哪一行、判成什麼類別。

## 步驟

1. 讀 `wiki/reader-notes.md` 檔頭，格式、狀態、類別以它為準，本檔不重述。
2. 判類別（🎨 版面建議／🔍 興趣主題／📝 內容修正／🐞 缺陷流程／📓 雜記）。拿不準就挑最接近的一個，回報時說出理由。
3. 寫一條：使用者原意（盡量保留原話）＋觸發脈絡（哪則新聞、哪段對話）＋當場查到的事實（標來源與日期）＋相關頁面的 wikilink。
4. 插在檔內第一條分隔線 `---` 之後（最新在上），狀態 ⏳；📓 雜記用 📌。
5. 回報檔名、類別、該條開頭一句。

## 邊界

- 執行者：主 session。
- 只新增一條；不改其他條目狀態，不清舊條目（那是 `/wiki-weekly-review` 的事）。
- 不寫記憶檔、不改 wiki 內容頁；使用者要求「查證後寫進 wiki」是 Query 通道（見 `.claude/skills/wiki-query/SKILL.md`），另走。
- 不 commit；使用者要求時只 add `wiki/reader-notes.md`。
- 驗證：回報前確認該條已在檔內且位置正確。
