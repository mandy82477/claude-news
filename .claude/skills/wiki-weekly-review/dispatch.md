# 週度延伸回顧派工與模板

`.claude/skills/wiki-weekly-review/SKILL.md` 的派工全文與格式單一來源。步驟不在本檔。

## 六記者派工 prompt（步驟 2）

每個 Agent 呼叫的 prompt：

```
今日日期：[YYYY-MM-DD]
任務：審視你負責頁面在過去 7 天的新增內容，做延伸判斷（只回報，不直接修改）：

有沒有主題本週被多次提及、正在成形，值得比現有篇幅更深入追蹤？例如：
- 該建立獨立頁面（目前只是附記在別頁的一兩句）
- 該在既有頁面加開新子區塊（目前分散在時序各處，缺乏彙整）
- 該提升熱度/優先度（目前標示的重要性明顯低估近期訊號量）

另外讀 `wiki/reader-notes.md`，找屬於你領域、狀態為 ⏳ 的 🔍 興趣主題（使用者主動表達想多看的主題）——這是**需求面證據**：使用者問過但現有覆蓋不足，也算加碼理由，即使本週新聞訊號不強。回報時註明該建議來自 reader-notes 哪一條。

判斷標準先 Read `.claude/rules/collection-scope.md`，對照其「目標讀者」（Claude Code 重度使用者 / AI 系統開發者 / Anthropic 生態追蹤者）與檔首的唯一判準——這份延伸能幫助這些讀者更了解 Claude/Anthropic 生態系嗎？若否，不建議。

給 0-3 條具體建議（沒有就寫「無」），格式：
## [頁面路徑/新主題名稱]
- 建議：[具體描述]（理由：[本週有哪些具體訊號支持這個判斷]）

最後一段總結全體中最值得優先處理的 1-2 件事。
```

## 月度聚焦校準（每月一次）

派一個 Sonnet agent（`model: "sonnet"`）：回讀 30 天前那一週的 `news/*.md`「今日聚焦」條目，逐條對照其後 30 天的日報與 wiki 頁面發展，判定：

- **命中**：有後續、長成故事線
- **誤報**：再無下文
- **漏報**：掃同週非聚焦區塊中後來爆發的條目

輸出：
```
| 聚焦條目 | 當時標籤 | 後續 30 天 | 判定 |
```
＋命中率＋偏誤模式觀察（如「Show HN 工具類系統性高估」）＋若有明確偏誤，附選材指引修正提案（目標：`.claude/skills/news-digest/selection.md`），**經使用者確認才修改**。

## 彙整確認清單（步驟 3）

```
## Wiki 週度延伸回顧（YYYY-MM-DD）

### 建議延伸
| 頁面/新主題 | 建議 | 理由 |

❓ 請確認要執行哪些項目（可全部 / 部分 / 都不要）
```

## log 條目（步驟 5）

`wiki/log.md` 末尾 append：

```
## YYYY-MM-DD 週度延伸回顧

- 延伸：（列出已執行項目，若無則寫「無」）
- 使用者跳過項目：（列出未採納的建議，若無則寫「無」）
- 聚焦校準：（月度才有：命中率＋偏誤模式觀察，或「非本月首次週度回顧，跳過」）
```
