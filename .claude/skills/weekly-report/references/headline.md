# 第 (1) 段：頭條

頭條講**本週最多讀者會在意的那一件事**，300–500 字，不列清單。

**選題**：主編選。動筆前寫三行給自己（不進週報）：影響面是讀者多數還是少數、有幾個獨立來源、同週有沒有影響更廣的。專文可以寫給窄讀者，頭條要打到最多人。

**標題**：`## 一、頭條敘事：` 冒號後一句話，≤60 字（格式見 `.claude/skills/weekly-report/references/contracts.md`）。一句只講一件具體的事，沒讀過本刊的人能照著覆述；用正文出現過的具體物（指令、產品、動作），不用撰稿者發明的抽象詞。

**正文**：
- 先講讀者碰到了什麼，再講為什麼會這樣、接下來會怎樣。
- 延續上週的線，第一句交代前情（什麼時候、發生什麼）再講本週新增了什麼；沒有新增就不上頭條。
- 數字第一次出現附來源連結；本刊自己的推論標「（本刊推論）」。
- 收尾一句告訴讀者要不要做什麼；沒事可做也寫明「目前不用動，等 X」。
- 頭條與專文同題時，頭條講為什麼重要，怎麼做留給專文，用一句話指過去。
