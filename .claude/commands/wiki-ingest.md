# Wiki Ingest

讀取今日日報，更新 wiki 知識庫。每天在新聞聚合器跑完後執行。

## 步驟

### 1. 確認今日日報

讀取 `news/$ARGUMENTS.md`（若無提供日期，使用今天的日期 YYYY-MM-DD）。
若檔案不存在，停止並告知使用者。

### 2. 載入 wiki 現況

同時讀取：
- `wiki/index.md` — 取得所有現有頁面清單
- `wiki/log.md` — 確認最近是否已處理過同一份日報（避免重複 ingest）

### 3. 判斷受影響的頁面

比對日報內容與 index.md 中的實體和議題，找出：
- 日報中提到的既有 entities（例如模型名稱、產品、人物）
- 日報中提到的既有 topics（例如定價爭議、功能趨勢）
- 日報中出現但尚無專頁的新實體或新議題

### 4. 更新既有頁面

對每個受影響的頁面：
- 在「歷史記錄」（entities）或「時序」（topics）區塊最上方插入新事件（最新在上）；這兩個區塊位於各自頁面的最末尾
- 若現況有變化，更新「現況」或「摘要」段落
- 若為 `topics/community-tech-patterns.md`，額外維護以下兩個區塊：
  - **熱門應用表格**：依當日討論熱度新增或調整排名，已有條目可升降熱度
  - **時序**：新增當日熱門技術應用條目
- 若為 topics/ 頁面，在「技術彙整」區塊累積新的技術細節：
  - 涉及的技術機制、API 行為、參數變化
  - 已確認的限制或已知問題
  - 社群發現的 workaround 或最佳實踐
  - 只新增尚未記錄的條目，不重複
- 同步更新「最後更新」欄位為今日日期

格式規範見 `CLAUDE.md`。

### 5. 建立新頁面（視需要）

**新 topics/ 頁**：若某個議題在日報中出現，且 log.md 顯示昨天也出現過同一議題，則建立新的 topics/ 頁。

**新 entities/ 頁**：若某個實體被日報明確描述（有具體資訊可記錄），建立新的 entities/ 頁。

頁面格式嚴格遵守 CLAUDE.md 中的模板。

### 6. 更新 feature-radar.md

依 CLAUDE.md 中的規則更新 `wiki/feature-radar.md`：
- 日報出現新的官方功能 → 在「最新功能」區塊新增條目 + 更新全覽表
- 已追蹤功能再次出現 → 熱度 +1 格（上限 🔥🔥🔥🔥🔥）
- 出現多個正面使用案例 → 試用價值升級
- 出現重大 bug 或集中負評 → 試用價值降級
- 功能從 Preview 升格正式發布 → 考慮升為 ✅，更新狀態欄

### 7. 更新 log.md

在 `wiki/log.md` 末尾 append 一筆記錄（不可修改既有條目）：

```
## YYYY-MM-DD Ingest

- 來源日報：[[news/YYYY-MM-DD]]
- 更新頁面：（列出修改的檔案）
- 新增頁面：（列出新建的檔案，若無則寫「無」）
- 摘要：（一句話說明今日主要新聞方向）
```

### 8. 更新 wiki/index.md

若有新增頁面，在 index.md 對應分類下補上連結。
格式與現有條目保持一致。同步更新頁面總數。

### 9. 完成前強制核對清單

**在宣告完成之前，逐項確認以下所有項目。若有任何一項未完成，繼續執行直到全部完成。**

- [ ] 所有受影響的 entities/ 頁面已更新（現況 + 歷史記錄）
- [ ] 所有受影響的 topics/ 頁面已更新（摘要 + 技術彙整 + 時序）
- [ ] feature-radar.md 已更新（熱度、試用價值）
- [ ] wiki/log.md 已 append 本次 ingest 記錄（且未修改既有條目）
- [ ] wiki/index.md 已同步新增頁面與頁面總數
- [ ] 所有修改頁面的「最後更新」欄位已更新為今日日期
- [ ] 未在 `CLAUDE_NEWS/wiki/` 以外的路徑建立或修改任何 wiki 檔案
- [ ] 沒有任何頁面出現重複的 `## 參考來源` 或其他重複區塊

完成後輸出一份摘要表格：

| 項目 | 內容 |
|------|------|
| 日報來源 | news/YYYY-MM-DD |
| 更新頁面 | （列出檔案名稱）|
| 新增頁面 | （列出或「無」）|
| feature-radar 變動 | （列出功能名稱與熱度變化，或「無」）|
| 今日主要方向 | （一句話摘要）|

## 注意事項

- 繁體中文為主，英文術語保留英文
- 每次修改頁面都必須更新「最後更新」欄位
- 所有 wiki 檔案只能建立或修改在 `CLAUDE_NEWS/wiki/` 路徑下，不可誤存至父層 ObsidianLab 目錄
- 若日報今日無新內容（來源全部失敗），在 log.md 記錄一筆「無新內容」即可，不需更新其他頁面
- `news/` 目錄為唯讀，不可修改日報內容
- 每個頁面只能有一個 `## 參考來源` 區塊——更新前先確認是否已存在，避免重複
