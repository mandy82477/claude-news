### ⭐ 重點話題

**Fable 5 解禁：Anthropic 與美國政府簽訂安全協議**

美國商務部長 Howard Lutnick 在社群媒體宣布解除對 Fable 5 的出口管制，稱已與 Anthropic 密切合作完成分析與核可。商務部信函顯示 Anthropic 承諾：主動偵測並解決安全風險、與美國政府合作制定標準協議、通報任何惡意活動。Fable 5 重新開放 Pro/Max/Team 及部分 Enterprise 方案用戶，7 月 7 日前享每週用量 50% 配額，之後改為依使用量計費。（ref: https://www.anthropic.com/news/redeploying-fable-5）

**Claude Code 隱寫術爭議**

安全研究者發現 Claude Code 2.1.196 的 binary 中含有特殊函式，能將當前日期的撇號（'）替換為同形字符、日期分隔符從 `-` 替換為 `/`，疑似用於隱寫識別目的。36Kr 報導進一步確認此機制針對時區資訊及中國 AI Lab 連線者。Anthropic 已回應並承諾修復。（ref: https://thereallo.dev/blog/claude-code-prompt-steganography）（ref: https://eu.36kr.com/en/p/3876461674917892）

**Claude Sonnet 5 成 Claude Code 新預設**

Claude Code v2.1.197 將 Sonnet 5 設為預設模型，API 定價僅 $2/$10 per Mtok（促銷至 8/31）。多篇社群評測確認 Sonnet 5 在 agentic 任務、coding、tool use 上已接近 Opus 4.8 水準，60% 成本差異吸引開發者關注。
