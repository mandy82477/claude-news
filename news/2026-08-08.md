### 📌 今日聚焦

- **[重大事件]** Anthropic 宣布 Claude Code 將於 8 月 14 日起把「auto 模式」設為預設權限模式；Hacker News 討論串中社群回饋多偏正面，有留言指出新款模型已大幅降低破壞性操作風險，作者提到已用 auto 模式執行數月的系統管理任務未出過重大差錯。[1][2]

- **[社群趨勢]** GitHub Issues 同時湧現多則高互動已知問題與功能請求：API 連線頻繁在回應途中中斷讓 Claude Code 近乎無法使用（44 則留言、82 個👍）、`autoMemoryEnabled: false` 未能抑制約 11–16k token 的記憶前導文字（40 則留言）、要求支援與 main 以外分支的 diff 比較（38 則留言、120 個👍）、跨機器 multi-agent 協作提案（Agent-to-Agent 協定，36 則留言）、內建 Slack 連接器支援多個 workspace 的功能請求（36 則留言、78 個👍）。[8][9][10][11][12]
