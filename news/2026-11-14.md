### 📌 今日聚焦

- **[新工具]** Anthropic 把 Claude Code 的 Projects 功能大改版：從「資料夾」變成「對話」，使用者描述目標後，Claude 自己拆解任務、派工、平行協調多條工作線、檢視產出再組裝成果，過程中隨時可從手機插話，人離開電腦後它仍繼續跑；beta 開放。Hacker News 拿到 93 分，另有一個來源同日報導。想一次丟多個子任務、不想自己手動拆工的人最有感。（[官方介紹](https://claude.com/resources/articles/projects-redesigned)）
- **[風險警示]** 資安業者 Apiiro 的掃描指出，GitHub 公開倉庫裡有 1,122 個 `.claude/settings.local.json` 檔案含真實機密：成因是使用者在權限提示按下「Yes, and don't ask again」，Claude Code 把這個「永久允許」規則寫進該檔，使用者再把整個專案資料夾 commit 上去時一併外流。習慣用「允許並不再問」跳過重複確認的開發者，建議現在就檢查自己倉庫裡有沒有把這個檔案 commit 上去。（[Reddit](https://www.reddit.com/r/ClaudeCode/comments/1xw6ls3/yes_and_dont_ask_again_can_commit_your_api_key/)、[Google News](https://news.google.com/rss/articles/CBMigAFBVV95cUxQa3dwS25MVk1WTURZeF9lZ1lfS3l1V3hTSi1wODBGMkd2S1ZJZjV2RW1MVHV1YXhzVmxRYUNWczVnUE5WOV90WXRlUDNTUWx4SElrUmlBNm5McnZ0SVBaUXFJN1RBYXcybG45TzR5N3ZtN2FtN3p4YnhsMi04dkEwSg?oc=5)）
- **[風險警示]** GitHub 上有使用者回報，Cowork 雲端沙盒的 egress 允許清單會自動收斂到約 5 個網域，即使帳號設定已明確選「All domains」；這則回報目前累積 35 則留言。用 Cowork 雲端沙盒、且工作流依賴存取自訂網域的人，目前的網域設定可能沒有照帳號端的選擇生效，建議先手動確認實際能連到哪些網域。（[GitHub Issue](https://github.com/anthropics/claude-code/issues/93525)）
