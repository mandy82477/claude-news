### 📌 今日聚焦

- **[重大事件]** Anthropic 正式發布 Opus 5 並全平台上線，官方稱其在多項基準測試（含 agentic search）表現優於 Fable 5，成本僅約後者一半。[1][2][3][4]
- **[重大事件]** Anthropic 部落格發文說明「Claude 5 世代模型的 context engineering 新規則」，揭露針對更先進模型已移除超過 80% 的 Claude Code 系統提示詞，並提供將此經驗應用於自訂 agent 的建議；該文在 Hacker News 獲 393 分討論熱度。[5]
- **[持續追蹤]** Opus 5 上線首日，Anthropic Status 頁面接連出現 4 起 Opus 5／Sonnet 5／Fable 5／Mythos 5 等模型錯誤率升高事件，皆在數十分鐘至約一小時內排除。[6][7][8][9]
- **[持續追蹤]** 社群長期訴求持續累積：要求支援 AGENTS.md 標準的 issue 互動熱烈，已累積 5760 個讚；另有使用者回報 API 連線中斷「嚴重到讓 Claude Code 無法完成任何任務」，以及頻繁迷失所在目錄等穩定性問題持續被提出。[10][11][12]
- **[持續追蹤]** 晶片與出口管制角力升溫：Nvidia 號召的開放權重連署已擴大到 50 家企業，但不含 Amazon 與 Anthropic；同時有報導指出 Anthropic 持續傾向推動對中國 AI 模型的出口限制，與 Nvidia 陣營立場對立。[13][14]

### ⭐ 重點話題

**多款 CLI Coding Agent 管理工具同批登場**
今日 Hacker News 同時出現三款鎖定「多 agent／多視窗管理」痛點的獨立工具：Termic（桌面應用程式，用於管理 Claude Code／Codex 等 CLI coding session）、Argus（VSCode worktree 多 agent session manager）、以及 terminai（把任意 CLI agent 整合進終端機）。三者切入角度不同，但共同反映「單一終端機難以管理多個平行 agent session」是目前普遍的痛點。
`Hacker News` · 07/26 09:36 UTC

**討論指出 Claude Code 對 Opus 5 存在硬編碼行為限制**
一則討論指出，Claude Code 2.1.219／220 版的編譯二進位中，內建一段僅針對 Opus 5 的兩行系統提示：除非使用者明確要求，否則不得呼叫 AgentTool、不得使用 workflows 或 deep-research。討論者認為此舉可能不成比例地限制了 Opus 5 的能力發揮，屬未經官方證實的社群觀察。
`Hacker News` · 07/26 08:45 UTC

**Claude Code 已知問題本輪集中出現多起高互動回報**
除 AGENTS.md 訴求外，本輪還有 Claude Code Desktop 在 Windows 因孤兒行程鎖定導致無法重啟（116 則留言）、Microsoft 365 連接器僅限 Team／Enterprise 方案而 Max 個人版無法使用（60 則留言）等回報同時湧現，顯示穩定性與功能落差仍是社群主要抱怨來源。
`GitHub Issues / claude-code` · 07/25 18:30 UTC
