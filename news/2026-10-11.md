### 💰 付費方案動態

**[官方文件新增：Auto Mode 分類器請求計費說明](https://code.claude.com/docs/en/auto-mode-classifier-billing)**
官方新增一頁說明：在 Auto 模式下，若 Claude Code 偵測到伺服器端的分類器檢查沒有送達你的 session（常見原因是中間有 LLM gateway 或 proxy 剝除、改寫了請求），Claude Code 會改用自己發出分類器請求，這些請求一如既往會計入你的 token 用量；文件明文寫出 Pro、Max、Team 方案在直連 API 時永遠不會看到這則通知。透過自架 gateway 連線 Claude Code 的團隊，應確認 gateway 有完整轉傳 `safeguards` 等欄位，否則分類器檢查的費用會悄悄算進自己的用量，或設定 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 明確關閉伺服器端檢查。
`Official Docs` · 10/11 16:21 UTC
