## ⭐ 重點話題

**[Claude Code sends your email address to websites](https://github.com/anthropics/claude-code/issues/107757)**
這個 issue 在 HN 累積 1,485 分、對應的 GitHub Issue 本身也同步跟進，是今天最熱烈的技術討論；開發者發現部分網站（例如 SEC API）要求 User-Agent 帶真實信箱才放行存取，Claude Code 會自動把使用者信箱塞進請求送出，而不是用假信箱或先詢問。會讓 Claude Code 存取需認證 API、又在意個資外流的開發者，應檢查目前的網路請求是否洩漏了自己的信箱。

**[Feature request: Connect Claude code to Claude projects](https://github.com/anthropics/claude-code/issues/2511)**
使用者要求讓 Claude Code 能直接讀取 Claude.ai Projects 裡建好的知識庫，不必再手動同步文件，這則需求累積 55 則留言、668 個讚，是全站讚數最高的一則。倚賴 Claude.ai Projects 管理長期知識庫、又想在 Claude Code 裡沿用的人，可持續關注官方是否採納。

**[Feature Request: Option to disable paste text collapse in input field](https://github.com/anthropics/claude-code/issues/23134)**
使用者要求能關閉貼上多行文字時自動收合成「[Pasted text #N +X lines]」的介面行為，認為需要逐行核對貼上內容時反而造成不便，累積 55 則留言、191 個讚。習慣貼長段文字給 Claude Code、事後又要逐行檢查的人，可留意這項設定是否會開放關閉。

**[[BUG] Copy-paste does not work](https://github.com/anthropics/claude-code/issues/66192)**
使用者回報 Claude Code 的複製貼上功能故障，累積 32 則留言、39 個讚跟進，官方尚未在 issue 裡說明修復進度。日常靠複製貼上在 Claude Code 與其他工具間搬內容的人，可留意這則 issue 後續是否有解法或暫時繞過方式。

**[[FEATURE] Portable project memory across machines (multi-device workflow)](https://github.com/anthropics/claude-code/issues/25739)**
使用者要求 Claude Code 的專案記憶能在多台機器間同步攜帶，而不是每台裝置各自累積一份獨立記憶，累積 29 則留言、47 個讚。常態在多台機器（例如公司電腦與個人筆電）間切換開發的人，可持續關注這項跨裝置記憶需求的進度。
