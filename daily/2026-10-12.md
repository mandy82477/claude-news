## 📌 今日聚焦

- **[社群趨勢]** Linux 核心作者 Linus Torvalds 被發現正用 Claude Code 開發一個新的 kernel 分支：新分支名為 `noref-filemap-read-with-llm`，是他在等待 Linux 7.3-rc7 發布、重新整理 repo 時意外出現的，不同於他過去幾乎只在主線 repo 推 master 的習慣；他先前曾在自己的 repo 外用 Google Antigravity 做過 vibe coding。追蹤重量級開源維護者採用 AI 工具狀況的工程師可留意這個分支後續會不會併入主線。（[Phoronix](https://www.phoronix.com/news/Linus-Torvalds-Claude-Code)）
- **[風險警示]** 一則 GitHub Issue 回報 Claude Code 出現嚴重記憶體洩漏，單一 session 吃掉 129GB 記憶體並導致系統整台當機，累積 66 則留言、58 個 👍反應；長時間掛著 Claude Code session 的使用者應留意系統記憶體用量是否異常升高。（[GitHub Issue #11315](https://github.com/anthropics/claude-code/issues/11315)）
- **[風險警示]** Cowork（Windows）在裝了某次 Windows 更新（KB5124008，組建 26200.9445）後，所有 Plan9 share 全數失敗、跳出「Plan9 mount failed: invalid argument」錯誤；回報者確認解除安裝該更新可修復，累積 120 則留言、61 個 👍反應，是今天所有條目中留言數最高的一起。用 Cowork 搭配 Windows 共享資料夾的使用者，官方修好前可先用這個暫時解法。（[GitHub Issue #92984](https://github.com/anthropics/claude-code/issues/92984)）

**[Feature Request: Persistent Memory Across Context Compactions (59 compactions, built our own)](https://github.com/anthropics/claude-code/issues/34556)**
