## ⭐ 重點話題

**[How the Claude Code team does code review](https://claude.dev/blog/solving-code-review-at-anthropic/)**
Claude Code 團隊撰文說明內部 code review 流程：目標不是追求「有沒有人看過」，而是在維持高覆蓋率與深度審查之餘，把人力審查時間壓到不會增加 revert 或事故的最低限度；文章同日在 Hacker News 拿下 396 分。長期煩惱 agent 產出的程式碼該怎麼設計審查流程的團隊可對照參考。

**[Anthropic Console overcharged my card 100x due to internationalization input bug](https://news.ycombinator.com/item?id=50121562)**
一名開發者投訴：在 Anthropic Console 儲值時因地區小數點輸入習慣不同打了「5.04」，系統卻把小數點整個吃掉、直接刷了 504 美元而非 5.04 美元，付款前也沒有任何確認視窗；貼文在 Hacker News 拿下 87 分。用非美式小數點輸入習慣儲值 API 額度的使用者，付款前應仔細核對金額再送出。

**[Sibling tool call errored: parallel tool calls cascade-fail when one fails](https://github.com/anthropics/claude-code/issues/22264)**
使用者回報 Claude Code 一次送出多個平行工具呼叫時，只要其中一個失敗，同批其他工具呼叫會被自動取消並標記為錯誤，而非各自獨立跑完；這則 issue 累積 35 則留言、64 個 👍 反應。重度依賴平行工具呼叫跑批次任務的使用者可留意這會不會讓單個工具故障拖垮整批操作。

**[Add support for Visual Studio 2026 Integration](https://github.com/anthropics/claude-code/issues/15942)**
社群要求官方讓 Claude Code 支援 Visual Studio 2026 整合，這則功能請求累積 155 則留言、587 個 👍 反應，是今天社群互動量最高的一則回報。在 Visual Studio 生態系開發、想在 IDE 內直接用 Claude Code 的團隊可追蹤這則 issue 後續進度。

**[\[BUG\] claude.ai visualize feature broken — claudemcpcontent.com unreachable (DNS_PROBE_FINISHED_NXDOMAIN)](https://github.com/anthropics/claude-code/issues/34820)**
使用者回報 claude.ai 的視覺化（visualize）功能完全無法運作，背後依賴的網域 `claudemcpcontent.com` 出現 DNS 無法解析的錯誤；這則 bug 回報累積 96 則留言、39 個 👍 反應。仰賴 claude.ai 視覺化功能做簡報或說明輸出的使用者，近期可留意官方是否已修復該網域。
