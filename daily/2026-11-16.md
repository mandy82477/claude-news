## ⭐ 重點話題

**[[BUG] Plan upgrade payment fails — PaymentIntent voided immediately with `void_invoice` before confirm can complete](https://github.com/anthropics/claude-code/issues/55982)**
這則回報累積 80 則留言、26 個 👍，是今日社群互動最高的議題：升級付費方案時，`PaymentIntent` 在使用者確認完成前就被 `void_invoice` 立即撤銷，導致升級流程失敗。正在升級方案卻卡住的人，可以先去這則底下確認是不是同一個問題，而不是急著重試或懷疑自己被重複扣款。

**[Make autonomous Claude Code actually viable: tiered Opus brains + Sonnet workers + persistent state](https://github.com/anthropics/claude-code/issues/56913)**
這則提案累積 50 則留言：主張把 Claude Code 架成長時間自主運作的「大腦」——用 Opus 做決策層、Sonnet 當執行層，再補上跨 session 的持久狀態，而不只是配對寫程式的助手。想把 Claude Code 架成長駐自動化系統、而非一次性對話的人，這串討論的架構方向值得追。

**[[BUG] Claude Desktop Windows installer fails with AddPackage HRESULT 0x80073CF6 after an earlier "successful" install left the package in an inconsistent state](https://github.com/anthropics/claude-code/issues/49917)**
這則回報累積 43 則留言、7 個 👍：Windows 版 Claude Desktop 安裝程式在前一次「看似成功」的安裝留下不一致狀態後，重新安裝會以 `AddPackage` HRESULT 0x80073CF6 失敗。在 Windows 上裝過 Claude Desktop、重裝時卡在這個錯誤碼的人，可能要先清掉上一次留下的套件殘留才能重裝。

**[[BUG] Cloud/Cowork sessions: git proxy now blocks all pushes — "not in this session's authorized repository set"; PAT pass-through no longer works (CCR_TEST_GITPROXY rollout?)](https://github.com/anthropics/claude-code/issues/76248)**
這則回報累積 42 則留言、19 個 👍：Cowork／雲端 session 推送到「未列入該 session 授權 repo 清單」的倉庫時被 git proxy 擋下，連使用者自己帶的 PAT 直通也不再生效，回報者推測與 `CCR_TEST_GITPROXY` 的推送機制調整有關。用雲端 session 推多個 repo、或依賴自帶 PAT 繞過授權清單的人，目前可能卡在推不上去。

**[[BUG] Cowork scheduled tasks ignore "Always allow" folder/tool permissions — prompts reappear every run (macOS)](https://github.com/anthropics/claude-code/issues/47180)**
這則回報累積 41 則留言、48 個 👍，反應數高於留言數：macOS 上的 Cowork 排程任務不記得「永久允許」的資料夾／工具權限設定，每次執行都重新跳出確認提示。靠 Cowork 排程跑無人值守任務的人，目前每次觸發都可能卡在等人按確認。
