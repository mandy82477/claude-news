## ⭐ 重點話題

**[Claude solves two open problems in the physics of black holes](https://www.anthropic.com/research/claude-black-hole-physics)**
Anthropic 研究團隊讓 Claude 完成兩道理論物理學界懸而未解的黑洞問題計算，其中一題是物理學家 20 多年前提出、始終沒人解出的計算，Claude 的結果顯示存在一個突然的轉變（細節未附）；這則討論在 Hacker News 拿到 133 分。關注 AI 能否做出原創科學貢獻、而非僅輔助寫程式的人，這是目前看到最具體的理論物理成果案例。

**[Support for AGENTS.md and .agents/skills/, the community has been asking since August 2025](https://github.com/anthropics/claude-code/issues/31005)**
一則自 2025 年 8 月就在等的功能請求，今天累積到 643 個反應與 38 則留言：社群要求 Claude Code 支援 AGENTS.md 與 `.agents/skills/` 標準，讓同一套設定檔能跨多個 agent 工具共用。同時維護多套 agent 專案設定、不想為每家工具各寫一份規則檔的人，這是目前看到最具體的訴求熱度數字。

**[[BUG] Drag and drop not working in VS Code extension chat panel (works in terminal CLI)](https://github.com/anthropics/claude-code/issues/25128)**
承上，同一套擴充套件還有另一個規模不小的已知缺陷：VS Code 擴充套件聊天面板裡拖放功能完全失效，但終端機 CLI 模式正常，回報指出這是近期版本引入的回歸；這則累積 41 則留言、63 個反應。靠拖放檔案或圖片進 VS Code 擴充套件工作流的人，官方尚未在今天的更新裡確認修復時程。

**[Show HN: Robotics needs better CAD, so I wrote a B-rep kernel and 3,487 tests](https://springcraft-ai.github.io/springrep/)**
Springcraft 共同創辦人用 Rust 寫了一套零依賴的 B-rep 幾何核心與 3,487 案例的一致性測試套件，兩者皆以 MIT 授權開源；作者表示「Claude Code 讓這件事變得可行」，這則在 Hacker News 拿到 32 分、兩個來源同日報導。做機械 CAD 或機器人零件建模、覺得現有核心功能不夠用的人可以看看。

**[Show HN: Zpup – Zdog style 3D scenes in JSON, SVG from any angle](https://github.com/rxolve/zpup)**
作者用 Claude Code Fable 5.2 寫出一個把 JSON 描述的小型 3D 場景轉成任意角度 SVG 的工具，取代多年未更新的 Zdog，改良了形狀重疊時的排序邏輯；兩個來源同日報導。想在 README 或 `<img>` 標籤裡嵌入 3D 示意圖、不想引入 JavaScript 渲染器的人可以看看。
