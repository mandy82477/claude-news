## ⭐ 重點話題

**[[BUG] Missing HCS services: vfpext - Cowork not working on Windows 11 Pro](https://github.com/anthropics/claude-code/issues/74649)**
官方 issue 回報 Windows 11 Pro 上因缺少 HCS 服務元件 `vfpext`，Cowork 功能無法正常使用；累積 87 則留言、7 個讚同反應，是今日 GitHub Issues 討論量最高的一則。在 Windows 11 Pro 上使用或評估 Cowork 的團隊可留意官方修復進度。

**[v2.1.150: scroll wheel no longer scrolls conversation — sends arrow keys instead](https://github.com/anthropics/claude-code/issues/65833)**
自 v2.1.150 起，Claude Code TUI 的滑鼠滾輪不再捲動對話內容、改送出方向鍵輸入；issue 累積 49 則留言、124 個讚同反應，反應數甚至高於留言數。仍停留在受影響版本的用戶，升級前可先確認是否已修復。

**[[FEATURE] Support diff comparison against branches other than main](https://github.com/anthropics/claude-code/issues/23626)**
社群要求 Claude Code 支援與非 main 分支比較 diff 的功能請求，累積 46 則留言、141 個讚同反應，為今日三則討論中讚同數最高者。常態在非 main 分支上開發的團隊可留意官方是否排入規劃。
