## ⭐ 重點話題

**[Cowork feature creates 10GB VM bundle that severely degrades performance](https://github.com/anthropics/claude-code/issues/22543)**
使用者回報開啟 Cowork 功能後，Claude Desktop 啟動變慢、介面卡頓、回應延遲，且效能會隨單一 session 時間拉長持續惡化；這則 issue 累積 271 個讚，是今天 Claude Code 系列 issue 中互動量最高的一起，重度依賴 Cowork 的使用者可暫緩升級或留意後續修補。

**[[BUG] Personal account repositories not visible in Claude web, only organization repositories work](https://github.com/anthropics/claude-code/issues/18467)**
使用者反映個人帳號（非組織）名下的 GitHub repo 完全不會出現在 Claude web（claude.ai/code）的 repo 清單中，只有組織名下的 repo 能正常顯示；這則 issue 已累積 86 個讚，獨立開發者或用個人帳號管理專案的使用者會直接撞到這個限制。

**[GLM 5.3 Flash opensource @ the top of Artificial Analysis Cyber Index over Claude.](https://www.reddit.com/r/LocalLLaMA/comments/1x1rwof/glm_53_flash_opensource_the_top_of_artificial/)**
社群貼出 Artificial Analysis Cyber Index（資安能力評測榜）最新排名，開源模型 GLM 5.3 Flash 登頂、名次超過 Claude；這是單一第三方榜單的快照，尚未見官方或其他獨立評測佐證，重視資安類任務模型選型的工程師可留意後續是否有更多測試結果出來。
