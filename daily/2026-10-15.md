## ⭐ 重點話題

**[Anthropic's Scion is heavily inspired by Mononoke](https://sunshowers.io/posts/anthropic-mononoke/)**
承上 10/13 Anthropic 工程部落格揭露的內部規模化改造，軟體工程師指出其中提到的新原始碼控制系統「Scion」用來加速 blame 等操作的「derived data」設計，幾乎與作者 2022 年描述 Meta/Oxide 的 Mononoke 系統時用的說法雷同；此文今日衝上 Hacker News 395 分，是本日互動最高的條目。

**[OpenTelemetry Arrives on Claude API, Traces Now in Public Beta](https://news.google.com/rss/articles/CBMikAFBVV95cUxQcWlJWDNkLWhpZ21iQ01mNGZLUFlBTHN0anU0SXRfc0UyVlRqZlV5RUlzOU1aUU5XaXJxSUpKU3UwT1otVG9Gd1BZajRNYnNLYkJFbVltS3NvN1ZsQlJOcFFsbzhyRElKX1YwTlhyeFRadjh1WmpWT2ZkREx3b1otU0ZOMENLUVJKMmUtSFllazA?oc=5)**
Claude API 原生 OpenTelemetry 追蹤功能進入公開測試：TypeScript 與 Python SDK（vertex-sdk v0.21.0、v1.14.0）同步發布，應用程式只要已註冊全域 tracer provider，升級後即自動建立並匯出 span，`open_telemetry=False` 或環境變數可關閉；2 家媒體同日跟進報導。已有可觀測性基礎設施的團隊升級後免改程式碼即可取得 Claude API 呼叫的追蹤資料。

**[Claude Code Desktop Vulnerability: Preview Pane Data Exfiltration](https://noma.security/noma-labs/sneakpeek-how-the-preview-pane-in-claude-code-desktop-can-exfiltrate-your-data)**
承上 10/14 只公開 CVSS 8.7 分數的揭露，資安業者 Noma Labs 今日公開完整攻擊鏈細節：攻擊者在公開 repo 放入偽裝成測試覆蓋率報告的惡意 HTML，藉此繞過預覽沙盒、在無 CSP 限制下執行 JavaScript，達成任意檔案讀取；官方尚未發布修補或回應。常在不明 repo 開啟覆蓋率報告預覽的使用者應提高警覺。

**[\[FEATURE\] Support Amazon Bedrock as backend for Claude Desktop / Cowork](https://github.com/anthropics/claude-code/issues/32668)**
要求支援 Amazon Bedrock 作為 Claude 桌面版／Cowork 的後端（如同 CLI 的 `CLAUDE_CODE_USE_BEDROCK=1`），累積 65 則留言、241 個 👍，是今天社群訴求最強的功能請求。企業內已用 Bedrock 跑 Claude Code CLI、想擴大到桌面版的團隊可追蹤此議題。

**[\[BUG\] MCP OAuth appends trailing slash to `resource` parameter, breaking Entra ID auth (AADSTS9010010)](https://github.com/anthropics/claude-code/issues/52871)**
MCP OAuth 流程在 `resource` 參數結尾多加一個斜線，導致 Microsoft Entra ID 驗證失敗（錯誤碼 AADSTS9010010），累積 50 則留言。用 Entra ID 做企業 SSO 串接 MCP 伺服器的團隊目前會卡在這個驗證錯誤上。
