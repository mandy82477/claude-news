## ⭐ 重點話題

**[How the Claude Code team thinks about verification](https://claude.dev/blog/how-the-claude-code-team-thinks-about-verification/)**
Claude Code 團隊發文說明：團隊內部約 90% 的程式碼由 Claude 自己寫並自己審，能撐住這個比例的關鍵是「驗證迴圈」——端對端測試、property test、差異測試讓 agent 自己拿證據證明工作做對了，有驗證迴圈才能同時平行跑幾十甚至上百個 Claude，否則只能一次顧一兩個。這篇在 Hacker News 拿到 194 分。想把 Claude Code 用在大規模平行自動化、而不是一次一個對話視窗的人，這篇給了團隊自己怎麼做驗證的具體方法。

**[[BUG] MCP OAuth appends trailing slash to `resource` parameter, breaking Entra ID auth (AADSTS9010010)](https://github.com/anthropics/claude-code/issues/52871)**
這則回報累積 52 則留言、33 個 👍：Claude Code 的 MCP OAuth 流程會在 `resource` 參數結尾多加一個斜線，導致接 Microsoft Entra ID 的身分驗證失敗並回報 AADSTS9010010 錯誤。用 Entra ID 做企業身分驗證串 MCP 伺服器的團隊，目前可能卡在這個斜線问题上。

**[[BUG] OAuth login fails with 500 error and 15s timeout — cannot authenticate via browser flow](https://github.com/anthropics/claude-code/issues/44271)**
這則回報累積 46 則留言、30 個 👍：透過瀏覽器進行 OAuth 登入時，後端回傳 500 錯誤並在 15 秒後逾時，使用者完全無法透過瀏覽器流程完成驗證登入。遇到 Claude Code 登入卡住、瀏覽器驗證跳不過去的人，先去這則底下確認是不是同一個已知問題。

**[Google DeepMind Strategy Chief Jasjeet Sekhon Departs for Anthropic](https://news.google.com/rss/articles/CBMipwFBVV95cUxPZVRLZVlmZ25lVzlRVjJvNDdGLVdYNmhxTDR5aUEyampVejh5TWtXZW41TUNjeWNpUWNBNVRyZU9jdmJBamJQS1pmQURCVDdYb2hKdXBtMlNhWlo0X2k1U3Y4UHZrM2hFbWN4Z1RqcHhXNlFtOXg0LUpTZWdUc3ZUdjh0RFNOWFQ3amZ6VHM5Ml84LXpiSUZuMnJ1M0s0Nkp2c1hoUkZxZw?oc=5)**
