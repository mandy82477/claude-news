## 🛠️ 功能

- 官方沒答的「規則寫了 Claude 真的會照做嗎」，社群有量化答案且是負面的：CLAUDE.md 明寫 TDD 六行規則，30 天提交審計顯示 60% 情況仍先寫碼後補測試 → [[topics/coding-workflow-guide]] → 靠 CLAUDE.md 規範測試紀律不可靠，要把 TDD 寫進指令或 hooks 才擋得住。
- 平行跑 4–5 個 agent 每天推近 90 次 commit，測試瓶頸從「測不測」移到「CI 撐不撐得住」，社群做法是本地合併佇列 → [[topics/coding-workflow-guide]] → 規模化平行 agent 前先算 CI 帳單，不是先加測試。
- v2.1.269 新增 `claude plugin eval` 指令，可對外掛執行評測套件並產出 JSON／HTML 報告 → [[entities/claude-code]] → 維護或發布 plugin 的開發者現在有官方評測工具可建 CI 品質門檻，一般使用者無需操作
- Windows 九月累積更新破壞 Cowork 的 device_bash（ARM64／x64 皆中，移除對應 KB 可恢復）→ [[entities/claude-code]] → 受影響者該先排查是否裝了該月 Windows 更新，不必懷疑 Claude Code 本身故障
- 桌面版 macOS 無法啟用 Bypass Permissions 模式，會自動退回 Accept Edits → [[entities/claude-code]] → macOS 使用者近期若要切換 bypass 權限模式，需留意可能不生效
