## ⭐ 重點話題

**[[BUG] Missing HCS services: vfpext - Cowork not working on Windows 11 Pro](https://github.com/anthropics/claude-code/issues/74649)**
Windows 11 Pro 使用者回報 Cowork 因缺少 HCS 服務 vfpext 而完全無法運作，此則今日累積 86 則留言，是今日互動量最高的 GitHub Issue。

**[Inter-session communication for multi-Claude workflows](https://github.com/anthropics/claude-code/issues/24798)**
開發者提出跨多個 Claude session 的通訊機制需求，用於串接大型專案裡有依賴關係的多階段工作流程，累積 84 則留言。

**[Claude Code does not respect the XDG Base Directory specification](https://github.com/anthropics/claude-code/issues/1455)**
Linux 使用者抱怨 Claude Code 把快取與設定寫進 `~/.claude.json`、`~/.claude`，未遵守 XDG Base Directory 規範，累積 68 則留言、447 個 👍 反應。

**[[BUG] Desktop: Bypass Permissions mode can't be enabled on macOS](https://github.com/anthropics/claude-code/issues/61415)**
桌面版 2.1.148 在 macOS 上無法開啟 Bypass Permissions 模式，會自動退回 Accept Edits 並提示「Permission mode couldn't be changed」，累積 65 則留言。

## 🛠️ 功能

### [[entities/claude-code|Claude Code]]

> **最新動態**
> - **v2.1.269 新增外掛評分指令**：`claude plugin eval` 可對外掛跑 eval 套件並產出 JSON／HTML 報告，外掛開發者能用它做升級前自動迴歸比對。
> - **桌面版 Git 需求放寬**：官方文件更新，只有用獨立 worktree 執行的 session 才需要裝 Git，非 worktree 使用者現在可以不裝。
> - **兩個平台限制影響使用**：Desktop（macOS）仍無法啟用 Bypass Permissions（#61415）；Windows 九月更新讓 Cowork device_bash 於 ARM64／x64 失效（#92958）。
> - **舊問題熱度上升、官方未給時程**：XDG Base Directory 不支援（#1455，447 讚）與 vfpext 缺失（#74649，86 則留言）持續是 Linux／Cowork 使用者的痛點。
