# 2026-09-12 今天 wiki 學到什麼

> 研究者用 8 種手法繞過 Claude Code 黑名單權限，只有白名單擋得住；另一份 30 天審計顯示 CLAUDE.md 寫了 TDD 規則，Claude 六成時候仍先寫碼。

## 🛠️ 功能

- dev.to 作者做了 30 天提交審計：CLAUDE.md 明寫六行 TDD 規則，Claude Code 仍有 60% 的情況先寫程式碼、事後才補測試 → [[topics/coding-workflow-guide]] → 靠 CLAUDE.md 規範測試紀律不可靠，要把 TDD 做成指令或 hooks 才擋得住。
- 一位開發者平行跑 4–5 個 agent、每天推近 90 次 commit，CI 被拖垮後改用本地合併佇列逐一測完再合 → [[topics/coding-workflow-guide]] → 規模化平行 agent 前先算 CI 帳單，瓶頸不在測不測。
- anthropic-sdk-python v1.5.0 為 Managed Agents 加上 auto mode 工具權限設定，是 5 月底以來四筆 SDK 更新中第一次列出具體項目 → [[entities/managed-agents]] → Managed Agents 還在動，但官方文件仍缺細節，選型時別把它當已定型。
- Claude Code v2.1.268 的 apps gateway 新增 pricing 設定，登入版客戶端經 managed settings 取得一致費率 → [[entities/claude-code]] → 團隊透過 gateway 用 Claude Code 的人，/cost 顯示的數字終於對得上實際帳單。

## 💼 商業
