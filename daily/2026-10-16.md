## ⭐ 重點話題

**[\[BUG\] API Error: Connection closed mid-response ==> frequent enough to make Claude Code unusable for any task](https://github.com/anthropics/claude-code/issues/69415)**
使用者反映 API 連線頻繁在回應中途被中斷，嚴重到讓 Claude Code 無法用於任何正式任務；累積 56 則留言、95 個 👍 反應，是今天三則臭蟲回報裡留言數最高的一起。長時間依賴 Claude Code 跑任務、近期常碰到回應中斷的使用者可追蹤此 issue 後續。

**[\[BUG\] Claude Code defaults to 1M context on fresh session with no workaround on Pro plan](https://github.com/anthropics/claude-code/issues/62063)**
開新 session 時 Claude Code 預設改用 1M context window，Pro 方案使用者反映找不到切回原本上下文長度的設定；累積 63 則留言、44 個 👍 反應。用 Pro 方案、在意額度消耗速度的使用者應留意新 session 預設的上下文長度是否符合預期。

**[\[BUG\] Desktop 2.37337.1: "Group by" option removed from Code tab sidebar — sessions now only grouped by environment](https://github.com/anthropics/claude-code/issues/102088)**
桌面版 2.37337.1 移除了 Code 分頁側邊欄的「Group by」自訂分組選項，session 現在只能按環境分組；累積 54 則留言、38 個 👍 反應。同時管理大量 session、習慣自訂分組方式的桌面版使用者會受影響。
