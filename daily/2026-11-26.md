## ⭐ 重點話題

**[社群把 Anthropic 的 GRH（廣義黎曼猜想）Lean 證明精簡了 99.56%](https://github.com/lsernau/grh-lean)**
社群成員把 Anthropic 原本約 1,700 萬行的 GRH Lean 形式化驗證，重寫成約 7.6 萬行就能跑完同樣的驗證，討論在 Hacker News 衝上 525 分，遠超過高互動門檻。關注 Claude 數學證明形式化驗證進度的人，這是比單純聲稱證明完成更進一步的「社群複核、證明本身被大幅精簡」訊號。

新專案讓 20 支 Claude Code agent 同時在 GitHub 免費 Runner 的 iOS 模擬器與 Android 模擬器上並行測試，找跑版、翻譯、排版與無障礙相關的 bug，上線即衝上 2,488 星。想把行動裝置測試自動化、不想自建裝置農場的團隊，這是今天新上榜的工具。

**[ffroliva/gflow-cli](https://github.com/ffroliva/gflow-cli)**
這款 MCP server／CLI 讓 Claude Code、Claude Desktop、Cursor、Codex 等工具能直接呼叫 Google Flow 產生 Veo 3.1 影片與 Nano Banana／Imagen 圖片，免費、MIT 授權，近 2 天暴增 289 星（約每天 144 星）。想在 agent 工作流裡直接出圖出片、不想自己串接 API 的人可以留意。
