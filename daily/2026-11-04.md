## ⭐ 重點話題

**[Linear Integration: Assign issues to Claude Code to trigger cloud agent sessions](https://github.com/anthropics/claude-code/issues/12925)**
使用者希望能直接在 Linear 指派 issue 給 Claude Code、藉此觸發雲端 agent session 自動處理，目前已累積 154 個讚與 47 則留言，官方尚未正式回應。常用 Linear 管理工程待辦事項的團隊可持續關注這項需求是否被納入路線圖。

**[[FEATURE] Task queue for queuing multiple prompts/tasks](https://github.com/anthropics/claude-code/issues/33323)**
使用者反映在複雜專案中常一次就知道接下來 3–5 件待辦，卻沒有辦法把多個任務排進佇列依序或平行執行，該請求已累積 65 個讚與 34 則留言。常需要一次丟多個指令給 Claude Code 的人，可留意這項功能何時成行。

**[Appllama/appllama-skills](https://github.com/Appllama/appllama-skills)**
這套把「年度營收最高 app 的設計模式」轉成原生品質行動畫面的 Claude Code agent skills 專案，近 8 天新增 1,413 星（約每日 177 星），成長速度遠高於一般倉庫，目前累積 4,795 星。做行動應用介面設計、想找現成 skill 的開發者可留意。

**[elvarofficial/teardown](https://github.com/elvarofficial/teardown)**
這款 Claude Code skill 能把任何機器轉成可拆解檢視的 3D 模擬器，目前累積 1,869 星，是今日 GitHub Search 抓到的倉庫裡星數次高者。對教學或產品拆解展示有興趣的工程師可留意。

**[OpenAI and Anthropic Set Up ‘War Rooms’ to Fight Disinfo About Midterm Elections](https://news.google.com/rss/articles/CBMiiwFBVV95cUxOWEZ5UW1FNFkxcXk5Y2pzN1hqR3dPZWdRRm9PT0phR3Y1cVg1N1E2RDk1ZWFCM2tCUnhvbVBHRVI0X2tfNEh6aFVmd3lxSGVvQ2s4SzRqQUFPMXJuUG5Sb19VMkpud1dBVVQ2VVBSMnM2WnhPLWVBTXFUZTlKcEJXRC1CcHdoUFZNWU5j?oc=5)**
