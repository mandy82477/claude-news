## ⭐ 重點話題

**[[BUG] Site permissions ("Allow all websites") ignored by the built-in browser in Claude Code Desktop](https://github.com/anthropics/claude-code/issues/91495)**
使用者回報 Claude Code Desktop 內建瀏覽器無視「允許所有網站」設定，每次仍跳出權限提示，目前累積 31 則留言與 33 個讚，官方尚未回應修復時程。常用 Desktop 內建瀏覽器跑自動化流程的人，會被反覆跳出的權限視窗卡住。

**[[BUG] Silent context degradation — tool results cleared without notification on 1M context sessions](https://github.com/anthropics/claude-code/issues/42542)**
issue 記錄三種機制（microcompact、cached microcompact、session memory compact）在 1M context 視窗下會悄悄清掉工具結果卻不通知使用者，累積 30 則留言與 11 個讚。靠長 context 視窗保留完整工具輸出做覆核的人，現在要留意輸出是否被悄悄砍掉而不自知。

**[Cannot log in to Claude Code: verification emails suppressed for my address, support bot has no escalation path](https://github.com/anthropics/claude-code/issues/79808)**
使用者反映自己的信箱被系統判定為「驗證信已停發」，導致無法登入 Claude Code，而官方客服機器人沒有人工升級管道，累積 29 則留言與 7 個讚。信箱收不到驗證信又卡在客服機器人迴圈的人，這則目前是唯一可追的對照串。

**[Desktop app: support custom themes / accent colors (parity with CLI custom theme system)](https://github.com/anthropics/claude-code/issues/79305)**
使用者要求 Desktop 版支援像 CLI 一樣的自訂主題與強調色，理由是目前僅有亮／暗兩色（含高對比），多數現代深色模式幾乎無法分辨視窗，累積 28 則留言與全站最高的 88 個讚。同時開多個 Desktop 視窗、靠顏色辨識專案的人，可持續關注這項需求是否納入路線圖。

**[[FEATURE] Passkey (WebAuthn) sign-in for Claude accounts, across every surface](https://github.com/anthropics/claude-code/issues/84862)**
使用者要求 Claude 帳號全平台支援 Passkey（WebAuthn）登入，累積 26 則留言，卻拿下全站最高的 209 個讚，顯示需求雖新但支持面很廣。在意帳號安全、想少打一次密碼的使用者可持續關注官方是否採納。
