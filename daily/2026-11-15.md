## ⭐ 重點話題

**[Mods - make Claude 10x more extensible](https://github.com/anthropics/claude-code/issues/91870)**
這則討論串自今年 10 月起追蹤 Claude Code「Mods」擴充功能的社群回饋，官方團隊持續在串內同步修復進度，今天累積到 277 則留言、225 個 👍。想了解 Mods 開發近況與已知問題的人，可以直接看這串最新的留言。

**[[BUG] Claude Desktop 1.1.3189 severe UI lag and mouse stutter on Windows — performance regression after update](https://github.com/anthropics/claude-code/issues/26302)**
這則回報指出 Claude Desktop 1.1.3189 版在 Windows 上出現嚴重 UI 延遲與滑鼠卡頓，是一次效能倒退，累積 56 則留言、48 個 👍。剛更新到這個版本、在 Windows 上使用 Desktop 介面變得卡頓的人，可以去這則底下補充佐證。

**[[FEATURE] Add font size adjustment for Code tab in Claude Desktop](https://github.com/anthropics/claude-code/issues/48237)**
這則功能請求希望 Claude Desktop 的 Code 分頁能調整字體大小，累積 37 則留言、135 個 👍，反應數明顯高於留言數，顯示訴求集中。常在 Desktop 的 Code 分頁看程式碼、覺得字級不合用的人，可以去加 👍。

**[Feature Request: Shared Team Memory for Claude Code](https://github.com/anthropics/claude-code/issues/38536)**
這則提案指出 Claude Code 的記憶系統目前只限個人使用，團隊成員間的知識無法互通，主張做出可共享的團隊記憶，累積 34 則留言、14 個 👍。多人共用同一個 repo、常得重複跟 Claude 解釋同一件事的團隊，可以關注這張需求單的後續設計方向。

**[Auto mode classifier blocks the account owner's own scheduled task ("Cowork Run Routine Now"), and blocked file transfer between the owner's own machines](https://github.com/anthropics/claude-code/issues/100730)**
這則回報指出 Cowork 雲端 session 的 auto mode 分類器，會把帳號擁有者自己排定的排程任務（`Cowork Run Routine Now`）與擁有者自己機器間的檔案傳輸都判定為需要額外確認而擋下，累積 26 則留言，並關聯另一則同類回報 #97613。用 Cowork 排程自動化、或常在自己的多台機器間搬檔案的人，目前可能會被系統誤判成未授權動作而卡住。
