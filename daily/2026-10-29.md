## ⭐ 重點話題

**[Claude Code regularly sends each background agent’s transcript to its model](https://gist.github.com/flamerix-ai/c3905705cc4205e5de3011fa2e74efce)**
社群成員發布分析與繞過腳本：Claude Code 每隔約 30 秒就會把每個背景 agent 的完整對話記錄重新送給模型，只是為了更新 agents 面板的狀態列；作者寫的 `no-agent-summary.js`（Bun --preload）可停掉這個計時器而不修改 Claude Code 本體，在 2.1.257–2.1.312 版本測試過。今日在 Hacker News 累積 527 分，是本日討論度最高的條目。同時跑多個背景 agent 的使用者，可留意這個行為對自己 token 用量的影響。

**[[Bug] Anthropic API Error: Connection closed mid-response](https://github.com/anthropics/claude-code/issues/70217)**
今日累積 33 則留言、22 個 👍，使用者回報 Claude Code 工作到一半常無預警出現「Connection closed mid-response」，回應被截斷、進度流失。長時間跑自動化或大型任務的使用者可留意是否已撞上這個中斷問題。

**[[BUG] Spell checking cannot be turned off, making all entered text hard to read](https://github.com/anthropics/claude-code/issues/58693)**
今日累積 31 則留言、18 個 👍，使用者回報目前沒有關閉拼字檢查的選項，輸入文字因紅色底線標記而難以閱讀。常輸入非英文或專有名詞的使用者可留意這個介面問題。

**[[BUG] cleanupPeriodDays: 99999 ignored — 490 sessions silently deleted despite explicit setting](https://github.com/anthropics/claude-code/issues/41458)**
今日累積 26 則留言、11 個 👍，使用者回報明確把 `cleanupPeriodDays` 設成 99999 仍遭忽略，490 個 session 在未被告知的情況下被靜默刪除。靠 session 歷史回溯過去工作內容的使用者，應留意這個設定目前是否真的有效保留記錄。
