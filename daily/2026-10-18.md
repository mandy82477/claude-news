## ⭐ 重點話題

**[Claude Code does not respect the XDG Base Directory specification](https://github.com/anthropics/claude-code/issues/1455)**
Linux 使用者回報 Claude Code 把快取與設定檔直接寫進 `~/.claude.json`、`~/.claude`，未遵循 XDG Base Directory 規範；這則長期開放的回報今日互動衝上 69 則留言、460 個 👍 反應。在意家目錄整潔、用 dotfiles 管理工具同步設定的 Linux 使用者可留意官方是否規劃遷移路徑。

**[\[FEATURE\] Add GitLab Integration (Repository Connection, MRs, Mobile Access)](https://github.com/anthropics/claude-code/issues/12346)**
社群要求官方讓 Claude Code 支援 GitLab 版本庫連接、Merge Request 與行動裝置存取，這則功能請求累積 55 則留言、159 個 👍 反應。在 GitLab 生態系開發、而非 GitHub 的團隊可追蹤這則 issue 是否排進官方路線圖。

**[\[BUG\] Permission prompt incorrectly triggers on cd instead of the actual command in compound bash statements](https://github.com/anthropics/claude-code/issues/28240)**
使用者回報 Claude Code 在組合式 bash 指令中，權限詢問視窗誤判成只對 `cd` 詢問、而非對真正要執行的指令詢問；這則回報累積 49 則留言、209 個 👍 反應。常寫多指令串接 bash 腳本的使用者應留意，核可前先確認完整指令內容。

**[\[Regression, Windows+macOS\] Cross-session messaging silently broken since CCD 2.1.224+ — messages dropped, recipient sessions wedged 15-20 min (hadFirstResponse=false); fixed in 2.1.237 for some installs, stable channel still affected](https://github.com/anthropics/claude-code/issues/86012)**
使用者回報桌面版 Claude Code 自 CCD 2.1.224 起跨 session 傳訊靜默失敗，訊息遺失、收訊 session 卡死 15–20 分鐘；部分安裝已在 2.1.237 修復，但穩定版頻道仍受影響。這則回報累積 42 則留言、9 個 👍 反應。用 Windows 或 macOS 桌面版且仰賴跨 session 傳訊協作的使用者，可先確認自己是否已更新到 2.1.237 以上。

**[Post/PreToolUse Hooks Not Executing in Claude Code](https://github.com/anthropics/claude-code/issues/6305)**
macOS 使用者回報 PreToolUse 與 PostToolUse hook 完全不會被觸發，這則回報累積 41 則留言、16 個 👍 反應。仰賴這兩個 hook 做工具呼叫前後置檢查或記錄的使用者，可留意官方修復進度再規劃升版。
