## ⭐ 重點話題

**[[BUG] CVP-approved Claude.ai organization still receives cyber safeguard blocks in Claude Code](https://github.com/anthropics/claude-code/issues/84352)**
一個先前已通過官方「網路驗證計畫」（Cyber Verification Program）審核的 Claude.ai 組織，近期又開始被 Claude Code 的網路安全防護機制擋下；這則回報今日衝上 201 則留言，是本日互動數最高的開發者回報。依賴 CVP 核准狀態放行內部工具存取的企業使用者，可留意驗證入口（Verification Portal）顯示的狀態是否與實際擋下情形一致。

**[[Windows] Desktop app: GPU process crash (exit code 101457950) kills entire app and all running sessions](https://github.com/anthropics/claude-code/issues/81698)**
Windows 11 搭配 NVIDIA RTX 5080 的使用者回報，桌面版某次 GPU 處理程序當機（錯誤碼 101457950）會直接拖垮整個應用程式與所有執行中的 session；這則回報累積 68 則留言。使用對應顯卡組合的 Windows 使用者，近期操作時可留意是否重複觸發同一錯誤碼。

**[[FEATURE] Allow Claude Code Web to start sessions from branches other than default branch](https://github.com/anthropics/claude-code/issues/10018)**
社群長期要求讓 Claude Code Web 能從非預設分支啟動新 session，而非永遠綁死在預設分支；這則請求今日累積 59 則留言，是本日互動數最高的功能請求之一。常態在 feature 分支上開發、不想每次手動切換的團隊，可持續追蹤官方是否排進路線圖。

**[[BUG]Claude Desktop repeatedly crashes and requires "Advanced Options → Repair" on Windows](https://github.com/anthropics/claude-code/issues/85199)**
另一則 Windows 桌面版回報指出 app 會反覆當機，使用者必須透過「Advanced Options → Repair」才能修復、且並非單一次事件；這則回報累積 52 則留言，與同日另一則 GPU 當機回報（見上）顯示本週 Windows 桌面穩定性問題不只一樁。仰賴桌面版日常工作的 Windows 使用者，遇到當機頻繁時可先試這個修復路徑止血。

**[[BUG] Cowork: new projects lost "Choose a folder" — Context menu replaced with Chat-style upload-only knowledge menu after Chat/Cowork merge](https://github.com/anthropics/claude-code/issues/76694)**
Cowork 與 Chat 介面合併後，新建專案原本的「選擇資料夾」選項消失，右鍵選單被換成僅支援上傳的 Chat 風格知識庫選單；這則回報累積 38 則留言。習慣讓 Cowork 直接讀取本機資料夾工作的使用者，近期新建專案時可能需要改用上傳，或等待官方補回選項。
