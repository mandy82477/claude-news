# 2026-11-14 今天 wiki 學到什麼

## 📌 今日聚焦

- **[新工具]** Anthropic 把 Claude Code 的 Projects 功能大改版：從「資料夾」變成「對話」，使用者描述目標後，Claude 自己拆解任務、派工、平行協調多條工作線、檢視產出再組裝成果，過程中隨時可從手機插話，人離開電腦後它仍繼續跑；beta 開放。Hacker News 拿到 93 分，另有一個來源同日報導。想一次丟多個子任務、不想自己手動拆工的人最有感。（[官方介紹](https://claude.com/resources/articles/projects-redesigned)）
- **[風險警示]** 資安業者 Apiiro 的掃描指出，GitHub 公開倉庫裡有 1,122 個 `.claude/settings.local.json` 檔案含真實機密：成因是使用者在權限提示按下「Yes, and don't ask again」，Claude Code 把這個「永久允許」規則寫進該檔，使用者再把整個專案資料夾 commit 上去時一併外流。習慣用「允許並不再問」跳過重複確認的開發者，建議現在就檢查自己倉庫裡有沒有把這個檔案 commit 上去。（[Reddit](https://www.reddit.com/r/ClaudeCode/comments/1xw6ls3/yes_and_dont_ask_again_can_commit_your_api_key/)、[Google News](https://news.google.com/rss/articles/CBMigAFBVV95cUxQa3dwS25MVk1WTURZeF9lZ1lfS3l1V3hTSi1wODBGMkd2S1ZJZjV2RW1MVHV1YXhzVmxRYUNWczVnUE5WOV90WXRlUDNTUWx4SElrUmlBNm5McnZ0SVBaUXFJN1RBYXcybG45TzR5N3ZtN2FtN3p4YnhsMi04dkEwSg?oc=5)）
- **[風險警示]** GitHub 上有使用者回報，Cowork 雲端沙盒的 egress 允許清單會自動收斂到約 5 個網域，即使帳號設定已明確選「All domains」；這則回報目前累積 35 則留言。用 Cowork 雲端沙盒、且工作流依賴存取自訂網域的人，目前的網域設定可能沒有照帳號端的選擇生效，建議先手動確認實際能連到哪些網域。（[GitHub Issue](https://github.com/anthropics/claude-code/issues/93525)）

## ⭐ 重點話題

**[Introducing Claude Meetings](https://claude.com/resources/articles/claude-meetings)**
Claude Meetings（11-10 以 beta 形式發布、開放 Team／Enterprise 方案）今天在 Hacker News 拿到 104 分討論，官方介紹頁描述 Claude 能以可見參與者身分加入視訊會議，邊聽邊動手做事、同步寫會議記錄與待辦事項。還沒試過這個功能的 Team／Enterprise 用戶，可以從今天的討論串先看別人怎麼用。

**[[BUG] MCP servers not properly terminated when Claude Code exits, causing orphaned processes](https://github.com/anthropics/claude-code/issues/1935)**
這則回報累積 48 則留言、20 個 👍：Claude Code 結束時沒有正確關閉 MCP 伺服器，留下孤兒行程持續佔用資源。常掛多個 MCP 伺服器、長時間開著 Claude Code 的人最容易累積殘留行程，目前得自己手動清。

**[[BUG] Output styles with YAML frontmatter not injected into system prompt](https://github.com/anthropics/claude-code/issues/47482)**
這則累積 41 則留言、4 個 👍：帶 YAML frontmatter 的 output style 雖然在狀態列與 `/config` 顯示已套用，實際內容卻沒被寫進 system prompt，移除 frontmatter 才正常——等於自訂語氣風格的功能目前形同沒生效。用自訂 output style 調整 Claude 說話方式的人，現在可能一直在用預設語氣而不自知。

**[Support multiple Gmail accounts in MCP integration](https://github.com/anthropics/claude-code/issues/36024)**
這則功能請求累積 36 則留言、88 個 👍：目前 Gmail MCP 整合一次只能接一個帳號，不少人同時有私人與公司帳號，盼能同時接多個。用 MCP 串 Gmail 處理公私信箱的人，這張需求單可以去加 👍 表態。

**[[BUG] Another program is currently using this file (AFTER UPDATE)](https://github.com/anthropics/claude-code/issues/51847)**
這則回報累積 32 則留言、18 個 👍：更新完 Claude Code 之後操作某些檔案會跳出「另一個程式正在使用此檔案」錯誤。剛更新完版本卻開始撞到檔案鎖錢誤的人，可以先去這則底下看有沒有人找到繞過法。
