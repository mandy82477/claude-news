03 · limits

我們 不做

時效
X 與 Discord 即時訊號
無法捕捉首發於社交平台的秒級爆料、漏洞回報與突發動態。
深度
企業內部非公開資訊
NDA 保護下的企業實測數據、內部佈署經驗，與未公開的產品路線。
語域
非英語系市場在地化
針對亞洲開發社群（日、韓、中）的特定 Bug 與應用案例觀測受限。
社群
IG / Discord 流傳的實用 Skill
財務分析、前端設計等實用型 Claude Code skill 多在 IG、Discord 擴散，不走 HN / Reddit 管道，無法自動收錄。遇到此類 skill 請手動告知補充。
for.
Optimized For

適合族群

  • Claude Code 重度使用者：想第一時間知道有什麼壞了、值不值得升版，不用自己刷 HN。
  • AI 系統開發者：在建 agent 或工作流，想知道社群驗證了什麼、踩過哪些坑。
  • Anthropic 生態追蹤者：關注政策、融資、合作動態，一站掌握生態走向。
not for.
Not For

不適合族群

  • 即時新聞工作者：需要追蹤社交平台秒級爆料與突發事件。
  • 影音學習者：以影音教學或互動 Demo 為主要學習方式。
  • 在地化專才：主要關注特定語系（日、韓、中）本地市場動態。
