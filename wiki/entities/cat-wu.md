## 現況

Cat Wu 是 Anthropic Claude Code 產品負責人（Head of Claude Code Products），與創始人 Boris Cherny（見 [[entities/boris-cherny]]）共同主導 Claude Code 的產品方向。2026-05-14，她在公開訪問中提出 AI 下一個重大躍進是「**主動性（proactivity）**」——AI 代理應能主動完成任務，而非等待使用者提示。這一論述與 Claude Code 同期推出的 `/goal`、`/loop`、`/batch`、`/background` 等自主執行指令套件方向完全呼應，是 Claude Code 從「互動工具」轉向「自主代理平台」的產品定位宣言。

## 公開言論

### 「AI 下一步是主動性（Proactivity）」（2026-05-14）

Cat Wu 接受公開訪問，指出：

> AI 的下一個重大躍進是**主動性（proactivity）**——AI 代理在不需要使用者提示的情況下，自主完成任務。

這一論述：
- 解釋了 Claude Code 為何以 `/goal`（fire-and-forget）、`/loop`（持續迴圈）、`/batch`（批次任務）、Agent View（多 session 統一管理）為核心功能方向
- 與社群 MCP 麥克風整合（語音驅動 Claude Code 主動發問）等工具的設計哲學高度一致；見 [[topics/community-tech-patterns]]
- 是繼 Boris Cherny「Loops 是未來」（2026-05-05）之後，另一位 Claude Code 負責人的公開設計哲學宣言，兩者共同構成 Claude Code 轉向 agentic 平台的官方論述
