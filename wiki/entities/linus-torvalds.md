## 現況

Linux 核心創造者。等待 Linux 7.3-rc7 發布、重新整理 `torvalds/linux.git` 時，意外發現自己 repo 多了一個新分支 `noref-filemap-read-with-llm`，不同於他過去幾乎只在主線 repo 推 master 的習慣；Phoronix 由此判讀他正用 Claude Code 開發這項 kernel 新功能（2026-10-12）。

此前他曾在自己 repo 外用 Google Antigravity 做過 vibe coding，也曾被引述稱某次「地獄等級」的除錯過程主要靠 AI 完成大量繁瑣工作，但未點名具體工具（2026-08-22，Simon Willison 部落格轉引其 commit 訊息）。
